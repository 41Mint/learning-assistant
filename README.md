# Learning Assistant - 学习助手

一个帮助游戏开发学习者保持学习动力和记录学习进度的Web应用。

## 项目概览

这是一个面向游戏开发学习者的记录与回顾工具：结合番茄钟和学习路径建立学习习惯，接纳来自视频、文档和项目实践的图文笔记，并允许随学习逐步补充理解与疑问。

## 核心功能

### MVP阶段（当前）
- [x] 番茄钟计时器（25分钟学习 + 5分钟休息）
- [x] 每日学习时长记录与统计
- [x] 连续学习天数（Streak）
- [x] Markdown 图文笔记导入、预览和历史补充
- [x] 技能树、自定义任务与当前学习目标联动
- [x] 包含本地图片和项目代码的完整 JSON 备份与恢复
- [x] 独立知识词条、分类目录、别名检索与日志双向关联
- [x] 项目代码快照、GitHub 固定链接与学习记录回链

### 后续计划
- [ ] 学习内容AI推荐（基于已学内容）
- [ ] 成就系统
- [ ] 项目代码版本对照
- [ ] 资源收藏管理
- [ ] 云端数据同步

## 技术栈

- **框架**: React 19 + TypeScript
- **构建工具**: Vite
- **样式**: Tailwind CSS
- **状态管理**: Zustand
- **图表**: Recharts
- **Markdown渲染**: react-markdown
- **数据持久化**: LocalStorage（文字与进度）+ IndexedDB（图片与项目代码）

## 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 使用固定端口启动（推荐，浏览器访问 http://localhost:5185）
npm run dev -- --port 5185

# 构建生产版本
npm run build
```

## 本地预览说明

本项目当前使用 Vite 本地开发服务器，并未部署为持续在线的网站。启动命令所在的终端或 Codex 任务关闭、系统休眠或重启后，服务器会停止，`localhost:5185` 也会暂时无法访问；重新运行固定端口命令即可恢复。

## 图文学习记录

页面按顶部五个入口组织，导航在滚动时保持可见：

- **今日学习**：番茄钟、当前目标、今日笔记与图文导入。
- **成长记录**：回看成果与实践，按领域筛选，查看预设成果、参考路径与任务。
- **历史回顾**：日期定位、旧笔记补充、学习统计与连续打卡。
- **知识词条**：持续补充自己的理解、分类检索、查看相关学习记录和相关词条。
- **数据管理**：完整备份与恢复。

地址中的 `#today`、`#path`、`#history`、`#knowledge`、`#data` 可直接定位入口。`#history/YYYY-MM-DD` 与 `#knowledge/词条ID` 支持直达记录或词条。今日、历史正文和词条采用独立编辑区，输入先进入草稿，点击保存后写入。切换入口保留草稿和计时，刷新前请保存需要保留的文字。

1. 在“今日学习记录”展开“导入图文学习记录”，选择实际学习日期、一个 Markdown 文件和配套图片（可多选）。
2. 点击“检查并预览”，确认图片匹配及图文效果。缺图或同名歧义会阻止保存；支持 PNG/JPEG/GIF/WebP，单图不超过 10 MB。
3. 点击保存；若该日期已有笔记，按钮会明确提示追加。原内容、时长、标签和知识点会保留。重复导入也会追加，请先核对日期和内容。
4. 切到“历史回顾”，使用“定位学习日期”回看。长文默认显示预览，点击“展开全文”阅读，顶部或文末可以收起；短文直接完整显示。通过“编辑 / 补充记录”添加新例子或问题；备份入口在“数据管理”。

导入和补充不增加学习时长、不自动打卡。图片可点击在新标签页查看原图；笔记引用的其他本地 `.md` 文件仍需到原资料目录查看。当前保持一天一条日志，不强制填写概念定义或掌握程度。

文字与图片均保存在当前浏览器、当前站点中，换浏览器或端口不会自动同步。验收步骤见 [图文记录验收指南](./docs/GRAPHIC_NOTES_ACCEPTANCE.md)。

## 知识词条

在今日/历史日志的“关联知识词条”中展开表单，选择已有词条，或只填名称后“新建并关联”。关联说明可记录“初次遇到，见 PPU 小节”等情境；点击词条名称进入专属页面，补充别名、分类和 Markdown 正文。也可以从“知识词条”入口独立新建。

一个日志可以关联多个词条，一个词条可以汇集多天日志；词条中的日期链接会返回原记录。词条改名不影响关联，删除词条只移除词条及其关联，保留原日志。旧知识点文字保留，可以手动建立词条关联。相关词条目前是手动、双向的“相关”关系，目录为单层分类。

词条操作可按 [知识词条验收指南](./docs/KNOWLEDGE_ACCEPTANCE.md) 回归验证。

## 成长记录

学习后打开“成长记录”，从“可以尝试”选一项成果并点击“我做到了”，也可以填写自己的成果名称。实践日期默认为当天，可以补记以往日期。说明和资料链接按需填写。同一成果可追加多次实践，每次可以分别关联多篇日志与多个知识词条。

“最近做到”按最近一次实践排序。一项成果可以属于多个领域。“参考路径与任务”可以展开浏览原有节点与任务，基础主题作为参考提示。当前目标可在“今日学习”的计时器上直接清除。

成长记录的操作步骤见 [成长记录验收指南](./docs/GROWTH_ACCEPTANCE.md)。

## 项目代码

展开今日或历史日志的“项目代码”，选一个 UTF-8 的 `.cs` 文件保存快照，或粘贴指向具体提交的 GitHub 文件链接。可以同时保存同一版本的文件与链接。再次导入同名脚本会另建版本。“成长记录”中的“项目代码”入口可按项目查看版本、补充仓库地址及编辑版本资料。

在词条与实践的编辑表单中，可以从“关联资料”选择代码版本及其他相关资料，一起保存。阅读词条时可从“项目用例”打开版本。代码详情可回到对应的日志、词条和实践。仅保存 GitHub 链接时，通过已登录且有权限的浏览器查看文件。

完整备份 v5 包含项目、脚本文本、固定链接与关联，继续接受 v1 至 v4。恢复采用整体替换，确认页面会提示旧备份缺少的内容。操作示例见 [项目代码验收指南](./docs/PROJECT_CODE_ACCEPTANCE.md)。

## 统一检索

点击顶部导航右侧的“检索”，可查学习日志的日期、正文、标签和知识点，词条的名称、别名、分类和正文，以及代码版本的项目名称、脚本路径和版本说明。用空格分隔多个关键词，结果会匹配每个词。结果按资料类型分组并高亮关键词。点击标题会跳到原资料的第一处可见命中，长日志有正文命中时自动展开。有编辑表单的目标页会在新标签打开，以保留原草稿。

在“代码版本”筛选中勾选“搜索脚本正文（本地快照）”，可按方法名等关键词查找保存的脚本内容。正文命中会显示行号，点开后滚动到该行并高亮关键词。只有 GitHub 固定链接的版本可按版本资料查找。

编辑词条或实践时，可在各类关联列表内筛选，已勾选的资料会随表单保存。定位与脚本搜索步骤见 [检索增强验收](./docs/KNOWLEDGE_ACCEPTANCE.md#6-检索增强)。

## 关系视图

在今日或历史日志、词条、代码版本中点击“查看关系”，进入以该资料为中心的独立关系图。卡片颜色区分资料类型，点击卡片可打开原资料。已有直接关联默认标为“相关”。点选连线可填写短标签和补充说明，保存后可从两端查看。每组最多显示六条连线。验收步骤见 [关系视图验收](./docs/KNOWLEDGE_ACCEPTANCE.md#7-关系视图)。

## 验证

```bash
npm run lint
npm run build
npm run test:e2e
```

浏览器测试使用隔离数据。Windows 默认使用本机 Edge；其他系统需要先运行 `npx playwright install chromium`。可通过环境变量 `DAY1_NOTE` 指定实际整理稿，额外验证其同级 `images/` 中的配图；未指定时跳过该真实材料用例。测试截图与报告不纳入 Git。

设置 `UNITY_SCRIPT_SAMPLE` 可用本机真实 `.cs` 文件验证快照导入。可选的 `UNITY_CODE_PERMALINK` 用于验证该文件对应的 GitHub 固定链接保存与回读。

## 开发理念

- **简洁实用优先**：轻度游戏化，避免过度设计
- **灵活可调整**：支持自定义每日学习流程
- **记录成长**：详细的学习日志帮助回顾和总结
- **持续迭代**：根据实际使用体验不断优化
- **生成式软件工程实践**：以“意图 → 可验收规格 → 实现 → 验证”的小步闭环与 AI 协作，详见 [ENGINEERING_PLAYBOOK.md](./ENGINEERING_PLAYBOOK.md)
