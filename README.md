# Learning Assistant · 学习助手

面向游戏开发学习者的本地 Web 应用。用番茄钟和学习任务安排今天的学习，把图文笔记、知识词条、代码版本和实践记录串起来，方便日后回查。

## 本地启动

安装 Git 和 Node.js 24 后，在项目目录双击 Windows 的 `start.bat` 或 macOS 的 `start.command`，即可检查更新并打开本地学习助手。[安装、手动启动与 DeepSeek 配置](./docs/SETUP.md)
