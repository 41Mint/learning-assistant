# Learning Assistant - 学习助手

一个帮助游戏开发学习者保持学习动力和记录学习进度的Web应用。

## 项目概览

这是一个面向游戏开发学习者的记录与回顾工具：结合番茄钟和学习路径建立学习习惯，接纳来自视频、文档和项目实践的图文笔记，并允许随学习逐步补充理解与疑问。

## 核心功能

### MVP阶段（当前）
- [x] 番茄钟计时器（25分钟学习 + 5分钟休息）
- [x] 每日学习时长记录与统计
- [x] 连续学习天数（Streak）
- [x] Markdown 图文笔记导入、预览和历史补充
- [x] 技能树、自定义任务与当前学习目标联动
- [x] 包含本地图片和项目代码的完整 JSON 备份与恢复
- [x] 独立知识词条、分类目录、别名检索与日志双向关联
- [x] 项目代码快照、GitHub 固定链接与学习记录回链

### 后续计划
- [ ] 学习内容AI推荐（基于已学内容）
- [ ] 成就系统
- [ ] 项目代码版本对照
- [ ] 资源收藏管理
- [ ] 云端数据同步

## 技术栈

- **框架**: React 19 + TypeScript
- **构建工具**: Vite
- **样式**: Tailwind CSS
- **状态管理**: Zustand
- **图表**: Recharts
- **Markdown渲染**: react-markdown
- **数据持久化**: LocalStorage（文字与进度）+ IndexedDB（图片与项目代码）

## 快速开始

本地启动推荐使用 Node.js 24。组员可按[测试工作区验收指南](./docs/TEST_WORKSPACE_ACCEPTANCE.md)使用项目自带的示例数据。

```bash
# 按锁文件安装依赖
npm ci

# 启动开发服务器
npm run dev

# 使用固定端口启动（推荐，浏览器访问 http://localhost:5185）
npm run dev -- --port 5185 --strictPort

# 构建生产版本
npm run build
```

## 本地预览说明

本项目当前使用 Vite 本地开发服务器，并未部署为持续在线的网站。启动命令所在的终端或 Codex 任务关闭、系统休眠或重启后，服务器会停止，`localhost:5185` 也会暂时无法访问；重新运行固定端口命令即可恢复。

## 图文学习记录

桌面主导航位于左侧，可收起文字，只保留图标。窄屏从页面菜单打开左侧抽屉。

- **今日学习**：番茄钟、当前目标、今日笔记与图文导入。
- **成长记录**：回看成果与实践，按领域筛选，查看预设成果、参考路径与任务。
- **历史回顾**：日期定位、旧笔记补充、学习统计与连续打卡。
- **知识词条**：持续补充自己的理解、分类检索、查看相关学习记录和相关词条。
- **数据管理**：完整备份、恢复，以及按「日志」「词条」「代码」浏览的回收站。

地址中的 `#today`、`#path`、`#history`、`#knowledge`、`#data` 可直接定位入口。`#history/YYYY-MM-DD` 与 `#knowledge/词条ID` 支持直达记录或词条。今日、历史正文和词条采用独立编辑区，输入先进入草稿，点击保存后写入。切换入口保留草稿和计时，刷新前请保存需要保留的文字。

1. 在「今日学习记录」的操作栏点击「导入图文学习记录」，在弹窗内选择实际学习日期、Markdown 文件和配套图片（可多选）。
2. 点击“检查并预览”，确认图片匹配及图文效果。缺图或同名歧义会阻止保存；支持 PNG/JPEG/GIF/WebP，单图不超过 10 MB。
3. 点击保存；若该日期已有笔记，按钮会明确提示追加。原内容、时长、标签和知识点会保留。重复导入也会追加，请先核对日期和内容。
4. 切到“历史回顾”，使用“定位学习日期”回看。长文默认显示预览，点击“展开全文”阅读，顶部或文末可以收起；短文直接完整显示。通过“编辑 / 补充记录”添加新例子或问题；备份入口在“数据管理”。

导入和补充不增加学习时长、不自动打卡。日志中的截图默认缩略显示，单击可切换尺寸，双击或选择「查看原图」打开图片详情。详情可在新标签页打开原图。笔记引用的其他本地 `.md` 文件仍需到原资料目录查看。当前保持一天一条日志，不强制填写概念定义或掌握程度。

可从「今日学习」或「历史回顾」删除日志，再到「数据管理」的回收站恢复正文、图片和仍有效的资料关联。原日期已有日志时，可选另一个空日期恢复。

编辑今日或历史日志时，可以在正文里直接粘贴截图，在实时预览确认后随日志保存。文字与图片均保存在当前浏览器、当前站点中，换浏览器或端口不会自动同步。验收步骤见 [图文记录验收指南](./docs/GRAPHIC_NOTES_ACCEPTANCE.md)。

### 学习智能体

点击浮动的学习智能体图标可打开窗口。桌面可拖标题栏和右下角调整位置及大小，右键菜单提供靠边与复位。窄屏使用底部抽屉。点标题栏的「−」可让出页面，点图标恢复此前的输入和结果。

窗口内可切换「自由问答」「日志整理」「查找资料」和「回看实践」。问答可按需引用当前日志，也可以输入「整理 11-5 的日志」「打开 PPU 词条」或「上次我怎么实现角色移动的？」从本地匹配结果中选择资料。进入日志整理后，点击生成，核对并勾选建议，再随日志一起保存。配置和验收见 [学习智能体](./docs/LOG_REVIEW_ACCEPTANCE.md)。

## 知识词条

在今日/历史日志的“关联知识词条”中展开表单，选择已有词条，或只填名称后“新建并关联”。关联说明可记录“初次遇到，见 PPU 小节”等情境；点击词条名称进入专属页面，补充别名、分类和 Markdown 正文。也可以从“知识词条”入口独立新建。

一个日志可以关联多个词条，一个词条可以汇集多天日志。词条中的日期链接会返回原记录。词条改名保留关联。删除的词条可从「数据管理」恢复原正文、图片及仍有效的关联，名称或别名重复时可调整后恢复。旧知识点文字保留，可以手动建立词条关联。词条可手动建立双向关联，目录为单层分类。

词条操作可按 [知识词条验收指南](./docs/KNOWLEDGE_ACCEPTANCE.md) 回归验证。

## 成长记录

「成长记录」包含「实践记录」和「想尝试」。在「实践记录」可以直接记下成果，也可以在同一张卡上追加多次实践。右键卡片或点「⋯」可记录、编辑和删除实践，或询问智能体。点标题可查看历次实践及其关联资料。

按住 `Shift` 点击卡片可加选，桌面上也可从看板空白处按住左键拖动框选。右键和「⋯」按整个选区移动、移出或询问智能体。整理操作可用工具栏图标撤销和重做，也可按 `Ctrl+Z` 撤销、`Ctrl+Shift+Z` 或 `Ctrl+Y` 重做。

桌面将鼠标移到顶栏下方的左侧图标栏即可展开导航。「成长记录」下面可进入参考路径和项目代码。在「想尝试」点「添加练习」，可自己填写或打开智能体推荐面板。推荐卡片可加入「想尝试」，也可用「我做到了」打开预填实践表单。点练习卡片标题可查看完整说明、验证方法及关联资料，菜单支持编辑和移出，已移出的内置练习可恢复。

主题卡组可以同时收纳「想尝试」和「实践记录」卡片。封面显示当前视图的卡片数量、领域标签和卡组说明，点击打开整个卡组。「⋯」可编辑说明、选中组内卡片或询问智能体。桌面上可将卡片和卡组拖到看板的间隙或末尾排序，也可在卡组内整理卡片。拖动卡片到另一张未分组卡片的中间可建组，拖到已有卡组可归组。排序支持撤销和重做。智能体推荐可拖到「想尝试」空白处收藏，或拖到「实践记录」空白处预填实践。

多选卡片后可从「询问智能体」获取分组建议。聊天中可核对每组成员、修改目标名称并逐组确认。确认一次记为一步整理，可在成长看板撤销或重做。

「实践记录」按最近一次实践排序，领域用不同颜色和文字标识。「参考路径与任务」支持添加、编辑和删除主题，可从主题详情询问智能体，并编辑其任务草稿后保存到该主题。卡片菜单的「带到今日学习」会把卡片显示为「练习参考」。主题任务用「设为目标」，在同一位置显示为「当前学习目标」。两种内容都可在「今日学习」移除。完成番茄钟时，日志会相应添加「练习参考」或「目标」标签。

智能体的「回看实践」可按成果、实践说明或关联脚本中的关键词查找。选择一次实践后，可以打开原实践和关联的日志、词条、代码，也可以改写并确认当前学习目标。目标会出现在「今日学习」，完成番茄钟时会写入当日日志标签。操作见 [成长记录验收指南](./docs/GROWTH_ACCEPTANCE.md)。

## 项目代码

展开今日或历史日志的“项目代码”，选一个 UTF-8 的 `.cs` 文件保存快照，或粘贴指向具体提交的 GitHub 文件链接。可以同时保存同一版本的文件与链接。再次导入同名脚本会另建版本。“成长记录”中的“项目代码”入口可按项目查看版本、补充仓库地址及编辑版本资料。

在带行号的脚本快照里选中代码后，点选区旁的「询问智能体」，也可以在代码中右键。聊天框的 `</>` 可直接按脚本版本和行号选取。发送前可勾选附近上下文，确认后才会发送给 DeepSeek。只有 GitHub 链接的版本可以先在 GitHub 中查看，或补充本地快照后使用片段问答。

单击脚本中的一行可高亮并在右键菜单中询问。想了解文件在项目里的作用时，选「询问脚本用途」。发送前会显示本次使用完整正文还是首尾片段，以及是否附带保存的职责或版本说明。

在“项目代码”点“导入项目目录”，选择本地 Unity 项目根目录。预览相对路径，勾选需要保存的 UTF-8 `.cs` 文件，再创建项目或更新已有项目的目录快照。打开项目卡片上的目录快照，可为目录或文件保存职责说明，并从脚本路径打开已有代码版本。

在词条与实践的编辑表单中，可以从“关联资料”选择代码版本及其他相关资料，一起保存。阅读词条时可从“项目用例”打开版本。代码详情可回到对应的日志、词条和实践。仅保存 GitHub 链接时，通过已登录且有权限的浏览器查看文件。

完整备份 v9 保存参考主题、任务、完成标记及引用关系，也包含日志、词条和代码版本回收站及项目代码。继续支持恢复 v1 至 v8 备份。恢复采用整体替换，确认页面会显示备份内容。操作示例见 [成长记录验收指南](./docs/GROWTH_ACCEPTANCE.md)。

## 统一检索

点击导航中的“检索”，可查学习日志的日期、正文、标签和知识点，词条的名称、别名、分类和正文，以及代码版本的项目名称、脚本路径和版本说明。用空格分隔多个关键词，结果会匹配每个词。结果按资料类型分组并高亮关键词。点击标题会跳到原资料的第一处可见命中，长日志有正文命中时自动展开。有编辑表单的目标页会在新标签打开，以保留原草稿。

在“代码版本”筛选中勾选“搜索脚本正文（本地快照）”，可按方法名等关键词查找保存的脚本内容。正文命中会显示行号，点开后滚动到该行并高亮关键词。只有 GitHub 固定链接的版本可按版本资料查找。

编辑词条或实践时，可在各类关联列表内筛选，已勾选的资料会随表单保存。定位与脚本搜索步骤见 [检索增强验收](./docs/KNOWLEDGE_ACCEPTANCE.md#6-检索增强)。

## 关系视图

在今日或历史日志、词条、代码版本中点击“查看关系”，进入以该资料为中心的独立关系图。卡片颜色区分资料类型，点击卡片可打开原资料。已有直接关联默认标为“相关”。点选连线可填写短标签和补充说明，保存后可从两端查看。每组最多显示六条连线。验收步骤见 [关系视图验收](./docs/KNOWLEDGE_ACCEPTANCE.md#7-关系视图)。

## 知识网络

从主导航打开“知识网络”。画布工具栏可搜索词条、日志和代码版本，切换图层、词条分类与一跳或两跳范围，以及进入全屏。右侧目录按词条分类展开。

在空白处按住左键拖动可平移画布，鼠标在画布内时按 Ctrl 滚动滚轮可围绕指针缩放。双击节点可打开原资料，拖动节点可临时移出原来的布局范围。“适应窗口”会把移动后的节点也纳入视野，“重置节点位置”可恢复自动排列。

在“图层与筛选”的“模块可见性”任意勾选词条分类，也可以在画布上右键模块标题，选择“隐藏此模块”或“仅显示此模块”。隐藏时该组词条与相连的线一起从画布隐藏。“只看跨模块关联”保留可见模块的词条，筛出模块之间的直接连线，以及至少两个可见模块直接关联的同一篇日志或同一代码版本。侧栏按模块对列出直接连线，点击结果可定位。打开原资料再在同一标签页返回，可继续原来的筛选、选中项、缩放和平移。见 [模块可见性与返回验收](./docs/KNOWLEDGE_ACCEPTANCE.md#9-模块可见性与返回)。

拖动模块标题可移动整组，包括学习日志和代码版本。右键日志或代码的标题可隐藏整组，从“图层与筛选”恢复。右键词条可在图内编辑。右键词条模块标题可重命名分类或勾选成员移到其他分类。

按住 Shift 单击节点或从空白处框选，拖动任一选中节点即可一起移动。侧栏可批量改分类，也可“仅查看所选”以检查所选节点之间的直接连线。需要追溯间接关系时，勾选“显示中间节点（两跳）”。它会在当前筛选范围内补出没有直连的所选节点之间经过一个中间节点的路径。返回完整视图可继续原来的选中项、筛选、平移和缩放。

在“仅查看所选”中打开节点或连线详情后，单击画布空白处可回到所选节点，按住左键拖动仍可平移。在 Edge 中，全屏编辑弹窗打开时，短按 Esc 可关闭弹窗并留在全屏。

用画布工具栏或 Ctrl+Z 撤销移动、复位、分类变更及图内词条编辑，用 Ctrl+Shift+Z 重做。手动布局与撤销记录保留到当前标签页刷新或关闭。见 [整组移动与图内编辑验收](./docs/KNOWLEDGE_ACCEPTANCE.md#10-整组移动多选与图内编辑)。

点连线图标进入连线模式，可以在图上选起点和终点，也可以用关键词查找。标签与说明可随连线一并保存，单击已有连线可编辑或移除。空白处右键或点工具栏的加号可新建词条。

开发环境下可从右下角「开发者工具」进入测试工作区。它在新标签页打开，使用独立的本地数据，包含日志、词条、代码、卡片、主题任务及回收站样例。恢复示例数据也在开发者工具面板内。见 [组员验收步骤](./docs/TEST_WORKSPACE_ACCEPTANCE.md)。

## 验证

```bash
npm run lint
npm run build
npm run test:e2e
```

浏览器测试在 5187 端口启动独立服务，使用隔离数据。Windows 默认使用本机 Edge，其他系统需要先运行 `npx playwright install chromium`。可通过环境变量 `DAY1_NOTE` 指定实际整理稿，额外验证其同级 `images/` 中的配图。未指定时跳过该真实材料用例。测试截图与报告不纳入 Git。

设置 `UNITY_SCRIPT_SAMPLE` 可用本机真实 `.cs` 文件验证快照导入。可选的 `UNITY_CODE_PERMALINK` 用于验证该文件对应的 GitHub 固定链接保存与回读。

## 开发理念

- **简洁实用优先**：轻度游戏化，避免过度设计
- **灵活可调整**：支持自定义每日学习流程
- **记录成长**：详细的学习日志帮助回顾和总结
- **持续迭代**：根据实际使用体验不断优化
- **生成式软件工程实践**：以“意图 → 可验收规格 → 实现 → 验证”的小步闭环与 AI 协作，详见 [ENGINEERING_PLAYBOOK.md](./ENGINEERING_PLAYBOOK.md)
