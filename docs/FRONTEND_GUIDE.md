# 前端样式与交互约定

页面和浮层沿用应用的明暗主题。颜色、边框和交互动效从 `--app-*` 变量取值。通用输入框和操作按钮使用 `.workspace-input` 与 `.workspace-button`。输入和按钮并排时，对齐控件底边，由同一处定义控件高度，并在窄屏检查长文本和禁用状态。[全局样式](../src/index.css)

## 明暗主题

首次打开跟随系统主题。桌面侧栏和窄屏抽屉的底部使用同一个切换按钮，图标和提示显示将要切换到的主题。手动选择保存在当前浏览器，个人工作区和测试工作区共用此设置。

页面、浮层和组件的明暗变体使用根节点的 `data-theme` 与 `--app-*` 变量，原生控件继承根节点的 `color-scheme`。验收时在同一页面往返切换，检查文字、边框、输入控件、下拉和滚动条，再刷新核对设置是否保留。[全局样式](../src/index.css) · [侧栏导航](../src/components/common/WorkspaceNavigation.tsx)

## 滚动条

页面、编辑框和选项列表里的滚动区域沿用全局细滚动条、透明轨道和 `--app-scrollbar-thumb`。长选项列表在弹层内滚动。系统强制配色时沿用系统滚动条。[全局样式](../src/index.css)

## 聚焦与键盘操作

文本框、下拉框和多行输入聚焦时用主题强调色边框和浅色光晕。标签要与控件关联。词条列表、知识网络目录及智能体建议卡片在悬停或键盘聚焦时用主题强调色标出标题。[全局样式](../src/index.css)

- **独立筛选按钮、工具栏图标和描边操作链接**。悬停及 `:focus-visible` 使用内侧细描边，保留控件原有底色和文字颜色。选中状态用固定底色表示，禁用按钮沿用禁用样式。
- **连在一起的文字切换入口**。Markdown 源码和预览、实践记录和想尝试、回收站分类共用 `SegmentedControl`。选中底色在组内平滑移动，Tab 焦点用文字下划线提示。路由入口使用链接和 `aria-current`，同页模式用按钮和 `aria-pressed`。减少动态效果时立即更新选中位置。[分段控件](../src/components/common/SegmentedControl.tsx)
- **原位辅助按钮**。导入图文学习记录、选择任务等 `.workspace-button` 用底色和文字颜色反馈悬停及键盘聚焦，保留静态边框。系统强制配色下使用可见的焦点轮廓。
- **实底主次按钮**。`.note-button` 保留操作层级的实底配色，键盘聚焦时用高对比细描边。
- **详情操作行**。日志、词条和代码版本的主按钮及描边链接共用 `--app-detail-action-height`，按行居中，窄屏允许换行。导入按钮继续靠左，文字操作按原有文字样式显示。

分别检查悬停、Tab 聚焦、选中与禁用状态，并在有裁切的区域检查焦点提示是否完整。[全局样式](../src/index.css)

日志标签支持双击原位编辑，触屏轻点或键盘激活也可进入。Enter 保存，Esc 或点开其他区域取消，保存或按 Esc 后焦点回到标签。[日志标签](../src/components/StudyLog/LogMetadataField.tsx)

## 展开与收起

普通折叠区可用 `details` 和 `summary`，沿用全局双向过渡。添加、编辑任务和项目代码等原位表单复用 `InlineReveal`，用 `aria-expanded` 表示状态。收起时立即让内部控件退出键盘焦点顺序，并把焦点交还触发按钮，过渡结束后卸载表单。时长和缓动使用 `--app-motion-duration` 与 `--app-motion-ease`。系统开启减少动态效果时，时长为零。[通用展开组件](../src/components/common/InlineReveal.tsx) · [全局样式](../src/index.css)

今日和历史日志的「选择任务」在关联列表下原位展开。多选列表沿用关键词筛选。新建时可搜索所属主题，提交后同时保存新任务与当前勾选的关联。保存失败保留输入，取消或收起丢弃本次未保存的更改。[日志任务关联](../src/components/StudyLog/LogTaskLinks.tsx)

成长记录的卡组封面、「卡组」下拉和检索共用卡组弹窗。看板上等高的「卡组」下拉和「新建卡组」排在领域筛选之后。组内卡片详情用带组名的返回链接，组内筛选和建卡收在「组内操作」。只有同时展示两种状态时才显示「实践记录」与「想尝试」分组标题。[卡组弹窗](../src/components/Growth/GrowthFolder.tsx)

成长记录的卡片和卡组封面在同一网格内保持等高。卡面标题一行，说明每段最多两行，超出部分用省略号。封面显示组内总张数，与打开后可查看的卡片一致。窄屏随网格宽度重新排版。[卡片网格](../src/components/Growth/GrowthCardGrid.tsx)

并排的次要操作需要横向展开时，将触发按钮放在这一组操作的末尾，展开面板与按钮等高对齐。组内「添加练习」的横向面板以边框划分，悬停展开，移开后收起。点击、轻点和键盘激活可打开同一组选项，空间不足时向下显示。Esc 先关闭选项，焦点回到触发按钮。动效沿用主题设置。[添加练习控件](../src/components/Growth/GrowthExerciseActions.tsx)

## 下拉列表与关键词筛选

- **固定选项**用原生 `select`。支持 `::picker(select)` 的浏览器用全局主题装饰列表，保留原生键盘和选择行为。其余浏览器与系统强制配色模式使用原生下拉面板。[Chrome 开发文档](https://developer.chrome.com/docs/modern-web-guidance/guides/forms/branded-select-styling)
- **可筛选或可新增的选项**用 `SearchableSelect`，例如词条分类筛选和参考主题领域。打开候选时可逐条浏览，输入后即时筛选。支持鼠标选择、方向键移动、Enter 确认和 Esc 关闭。固定候选的筛选文字和已选项分开保存。自填模式适合需要新增分类或领域的表单。
- **浮层样式**。面板靠近触发控件展开。关键词筛选列表与控件同宽，紧凑的固定选项菜单可以按文字宽度加宽，空间不足时调整展开方向。用视口约束菜单尺寸，给长名称留出换行空间和选中标记位置。浮层使用主题表面、圆角、限高和细滚动条。Esc 优先关闭最内层浮层。验收覆盖明暗主题、窄屏、弹窗和全屏画布。
- **文字筛选**。实时搜索和筛选输入设 `autoComplete="off"`。应用需要展示候选时使用同一套带定位和键盘操作的列表。
- **多选资料**用 `ReferenceChoices`。筛选只影响当前显示的选项，其他已勾选的选项继续保留。
- **卡片领域**复用 `GrowthDomainFields`。常用领域用复选框，自定义领域用文本框。Enter 或「添加」将名称加入当前选择，直接保存也会录入已填写的领域。长名称可以换行，领域筛选和卡组封面同步使用保存后的名称。[卡片领域](../src/components/Growth/GrowthDomainFields.tsx)
- 复用 `searchWords` 和 `matchesWords`。空格分隔的词须全部匹配，可分布在不同搜索字段。日志可按日期、标题、标签、知识点或正文筛选。测试时覆盖空输入、无匹配、键盘确认以及选择后执行操作。

[单选组件](../src/components/common/SearchableSelect.tsx) · [多选组件](../src/components/common/ReferenceChoices.tsx) · [检索规则](../src/utils/resourceSearch.ts)

## Markdown 编辑与代码显示

日志和词条共用 `MarkdownFields`。仅显示图标的工具按钮提供可访问名称和悬停提示。格式按钮应用到当前选区或光标所在行，预览时为禁用状态。插入引用后回到源码和插入位置。格式操作在浏览器支持时进入原生撤销栈。[Markdown 编辑组件](../src/components/common/MarkdownFields.tsx) · [浏览器编辑历史](https://developer.mozilla.org/en-US/docs/Web/API/Document/execCommand)

今日和历史日志的源码工具栏「插入」与编辑区右键共用一个纵向面板。面板紧邻图标或右键位置，靠近视口边缘时调整位置和高度。在原面板内切换插入选项和搜索，候选复用 `SearchableSelect` 的行内列表。选中文字用作初始关键词，Esc 恢复原选区和编辑焦点。Shift 加右键可打开浏览器菜单。正文词条引用继承正文颜色并用虚线下划线标识，仍可通过 Tab 聚焦和激活。日志的知识关联由关联区单独管理。[插入选项](../src/components/StudyLog/LogInsertOptions.tsx)

本地图片和表格在同一面板完成选择与插入，分隔线直接插入。三者在光标或选区末尾生成独立的 Markdown 块。图片选择支持多选，预览和正式保存沿用粘贴截图的图片流程。表格选择正文行数和列数，插入后选中第一个表头，方便直接填写。

H2 位于格式工具末尾。空白足够时，鼠标悬停或 Tab 聚焦可向右展开其他标题级别，鼠标移出整组后收起。桌面可直接点 H2 应用二级标题。触屏点按展开，空间不足时在原工具栏内选择 H1～H6。键盘焦点在标题组内时，Esc 收起并将焦点交还给 H2。选择级别会应用到光标所在行或选中的行，重复选择同一级别可恢复正文。横向展开沿用全局动效设置。[Markdown 工具栏](../src/components/common/MarkdownToolbar.tsx)

「源码」和「预览」在同一编辑区切换，各自记住滚动位置，源码保留选区。预览图按比例限宽限高，普通图片可点击查看原图。编辑区域右下角的拖动手柄与滚动条分开，支持鼠标和触屏拖动、方向键调整以及 Enter 恢复默认高度。两种模式共用高度，宽度跟随页面布局。验收时检查长文、截图、模式切换和窄屏。[Markdown 编辑组件](../src/components/common/MarkdownFields.tsx)

源码的高亮层跟随原生文本框的字体、换行、滚动和尺寸。Markdown 语法按原文位置配色，带语言标记的代码块沿用现有高亮。输入法组字、系统强制配色和超长文档使用原生文本显示。预览与阅读中的行内代码沿用正文文字颜色，配以中性色背景与细边框，两种主题使用各自的颜色变量。[源码高亮](../src/components/common/MarkdownSourceHighlight.tsx)

词条引用和代码引用共用轻量的预览浮层。鼠标悬停或 Tab 聚焦时打开，Esc 收起，激活原链接查看详情。词条预览展示标题、分类和正文摘录。浮层使用应用的主题表面，贴近链接并避开视口边缘。[引用预览](../src/components/common/CitationPreviewLink.tsx)

Markdown 代码块、项目快照与代码引用预览共用语法高亮、行号和定位颜色变量。日间在原有色相内调整明度，让语法颜色和普通正文更容易区分。夜间使用基于 [One Monokai](https://github.com/azemoh/vscode-one-monokai) 的配色。两种主题共用本地打包的 [Fira Code](https://github.com/tonsky/FiraCode) 字体。验收时切换明暗主题，检查 Markdown 源码、代码片段、行号与引用范围。[全局样式](../src/index.css)

C# 在各处共用扩充后的 Highlight.js 语法规则。规则按片段内的写法区分命名空间、类型、属性、成员访问和成员方法调用。未匹配的写法由原有语法规则处理。新增标记沿用主题中现有的颜色。[高亮配置](../src/utils/codeHighlight.ts)
