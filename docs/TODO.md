# 待办事项

此处维护待验证的需求和后续工作。已交付的变更见[更新日志](../CHANGELOG.md)。

## 课设交付优先

- [ ] **查找资料并回答问题**。从自然语言问题提取检索线索，用已有日志、词条、代码快照和实践记录回答，并给出可回查的来源。验收时覆盖有证据、只有部分证据和没有匹配资料的情形。
- [ ] **验收智能体主流程**。用同一组学习资料串起日志整理、带来源的实践复盘和代码问答。核对真实模型答案与原文依据，确认建议可编辑后采纳，失败时可重试。

## 同学试用反馈

这些问题来自整理 Godot 学习笔记的试用。

- [ ] **Markdown 输入提示**。在词条编辑区提供空行分段、有序列表和段内换行的简短示例。
- [ ] **连线候选分组**。知识网络的起点与终点先按词条、日志和代码分组，词条再按现有分类展示，保留关键词筛选。
- [ ] **拖动后的分类归属**。先验证节点移出分类框后如何辨认原分类，再评估自动调框或主动收拢，避免大框遮挡其他分类。
- [ ] **多级知识导航**。用「Godot 3D → 场景空间构建 → 物理系统搭建」验证是否需要目录层级、概念关系，或两者兼有。

## 后续功能候选

- [ ] 用已有实践细化参考主题任务，从智能体问答准备可编辑的实践草稿。
- [ ] 评估日志 Markdown 导出、无引用图片清理、词条正文小节定位与长文阅读体验。
- [ ] 按实际项目规模评估导入远程目录、代码版本对照和项目任务组织。
- [ ] 用真实学习记录评估提醒、音效、自定义番茄时间、长休息与番茄钟统计。
- [ ] 用真实学习反馈调整预设路径，评估复习提醒、主动推荐、成就与资源收藏。

## 课设交付后推进

- [ ] **快速补记**。来自组员试用反馈。在一天一条日志的基础上，提供连续添加简短记录的入口。今日与历史按添加顺序展示，仍能编辑整篇 Markdown。
- [ ] **按日学习安排**。用习惯分时段学习的使用者验证上午、下午、晚上排事项、临时挪动和开始任务。复用已有任务与实践条目，同一份日程可从「今日学习」执行、从「历史回顾」查看。对比独立「学习安排」入口与「任务与安排」内的按主题、按日期视图。

## 以后再评估

- 更密集的数据规模下的可访问性、加载和滚动表现。
