# 使用指南

安装和启动见 [本地环境指南](./SETUP.md)。组员试用可直接按 [测试工作区验收](./TEST_WORKSPACE_ACCEPTANCE.md) 操作。

## 今日学习与图文记录

桌面主导航位于左侧，可收起文字，只保留图标。窄屏从页面菜单打开左侧抽屉。

- **今日学习**可使用番茄钟，查看当前目标及导入、编辑今日笔记。
- **成长记录**可回顾实践、收藏练习和整理卡组。下方有参考路径与任务、项目代码入口。
- **历史回顾**可按日期查找、补充笔记，并查看学习统计与连续打卡。
- **知识词条**可分类检索及补充理解。**知识网络**可浏览不同资料的关联。
- **数据管理**可导出和恢复完整备份，并查看日志、词条与代码回收站。

左侧导航底部的太阳或月亮可切换明暗主题。首次打开跟随系统主题，手动选择后浏览器会记住设置。

地址中的 `#today`、`#path`、`#history`、`#knowledge`、`#data` 可直接定位入口。`#history/YYYY-MM-DD` 与 `#knowledge/词条ID` 支持直达记录或词条。今日、历史正文和词条采用独立编辑区，输入先进入草稿，点击保存后写入。切换入口保留草稿和计时，刷新前请保存需要保留的文字。

1. 在「今日学习记录」或「历史回顾」的日志操作栏点击「导入图文学习记录」，选择 Markdown 文件和配套图片（可多选）。历史回顾默认使用当前查看的日期，可在弹窗中修改。
2. 点击“检查并预览”，确认图片匹配及图文效果。缺图或同名歧义会阻止保存；支持 PNG/JPEG/GIF/WebP，单图不超过 10 MB。
3. 点击保存；若该日期已有笔记，按钮会明确提示追加。原内容、时长、标签和知识点会保留。重复导入也会追加，请先核对日期和内容。
4. 切到“历史回顾”，使用“定位学习日期”回看。长文默认显示预览，点击“展开全文”阅读，顶部或文末可以收起；短文直接完整显示。通过“编辑 / 补充记录”添加新例子或问题；备份入口在“数据管理”。

导入和补充不增加学习时长、不自动打卡。日志中的截图默认缩略显示，单击可切换尺寸，双击或选择「查看原图」打开图片详情。详情可在新标签页打开原图。笔记引用的其他本地 `.md` 文件仍需到原资料目录查看。当前保持一天一条日志，不强制填写概念定义或掌握程度。

可从「今日学习」或「历史回顾」删除日志，再到「数据管理」的回收站恢复正文、图片和仍有效的资料关联。原日期已有日志时，可选另一个空日期恢复。

编辑今日或历史日志时，可以在「源码」里直接粘贴截图，用工具栏的「预览」核对，再随日志保存。两种模式分别记住滚动位置，可以从右下角调整编辑区高度。文字与图片保存在当前浏览器及站点下。[图文记录验收指南](./GRAPHIC_NOTES_ACCEPTANCE.md)

### 学习智能体

点击浮动的学习智能体图标可打开窗口。桌面可拖标题栏和右下角调整位置及大小，右键菜单提供靠边与复位。窄屏使用底部抽屉。点标题栏的「−」可让出页面，点图标恢复此前的输入和结果。

在同一个输入框直接描述想做的事，例如「整理 11-5 的日志」「打开 PPU 词条」或「回看点击目标的实践」。问答可按需引用当前日志。日志整理的建议可以在对话中按名称或编号继续编辑，再确认保存。是否从本地检索资料，以及当前引用了哪篇日志，可从对话中的结果和引用查看。[配置 DeepSeek](./SETUP.md#配置-deepseek) · [智能体验收](./LOG_REVIEW_ACCEPTANCE.md)

从引导卡片或快捷问题打开「查找资料」。搜「预制体」后可问「搜索结果涵盖哪些内容？」，点「按结果回答」会使用当前筛选。清空关键词后，可直接问「源预制体和实例覆盖值有什么关系？」，让智能体按问题查找。DeepSeek 会收到问题和最多六份匹配摘录。每条结论附来源链接，依据不足时会标出缺少的内容。[资料问答验收](./LOG_REVIEW_ACCEPTANCE.md#查找资料并回答)

问「我最近的实践记录有哪些」可查看按日期排列的实践。问「总结一下近几天的学习内容」会默认总结最近三篇有正文的日志，显示实际日期和来源。问「结合最近的学习内容给出今天的练习建议」可根据这些学习记录生成带来源的练习卡片。[近期学习验收](./LOG_REVIEW_ACCEPTANCE.md#最近实践与学习内容)

## 知识词条

在今日/历史日志的“关联知识词条”中展开表单，选择已有词条，或只填名称后“新建并关联”。关联说明可记录“初次遇到，见 PPU 小节”等情境；点击词条名称进入专属页面，补充别名、分类和 Markdown 正文。也可以从“知识词条”入口独立新建。

编辑词条时，在源码工具栏点「＋」或右键正文，即可插入本地图片、表格、分隔线、词条链接和代码版本链接。切到「预览」检查效果，再点「保存词条」。

一个日志可以关联多个词条，一个词条可以汇集多天日志。词条中的日期链接会返回原记录。词条改名保留关联。删除的词条可从「数据管理」恢复原正文、图片及仍有效的关联，名称或别名重复时可调整后恢复。旧知识点文字保留，可以手动建立词条关联。词条可手动建立双向关联，目录为单层分类。

词条操作可按 [知识词条验收指南](./KNOWLEDGE_ACCEPTANCE.md) 回归验证。

## 成长记录

「成长记录」包含「实践记录」和「想尝试」。在「实践记录」可以直接记下成果，也可以在同一张卡上追加多次实践。右键卡片或点「⋯」可记录、编辑和删除实践，或询问智能体。点标题可查看历次实践及其关联资料。

按住 `Shift` 点击卡片可加选，桌面上也可从看板空白处按住左键拖动框选。右键和「⋯」按整个选区移动、移出或询问智能体。整理操作可用工具栏图标撤销和重做，也可按 `Ctrl+Z` 撤销、`Ctrl+Shift+Z` 或 `Ctrl+Y` 重做。

桌面将鼠标移到顶栏下方的左侧图标栏即可展开导航。「成长记录」下面可进入参考路径和项目代码。在「想尝试」点「添加练习」，可自己填写或打开智能体推荐面板。推荐卡片可加入「想尝试」，也可用「我做到了」打开预填实践表单。点练习卡片标题可查看完整说明、验证方法及关联资料，菜单支持编辑和移出，已移出的内置练习可恢复。

主题卡组可以同时收纳「想尝试」和「实践记录」。封面显示组内总张数、领域标签和说明。该组有符合当前看板和领域筛选的卡片时，封面会出现在看板上。点封面或用工具栏的「卡组」下拉可以打开弹窗。进入卡片详情后，用带组名的返回链接回到卡组。

展开「组内操作」可以按领域筛选、记录自定义成果或添加练习。悬停「添加练习」可向右展开选项，点击或按 Enter 也可打开。选择「让智能体推荐」会带入组名及已选领域，生成后可从卡片菜单「加入此卡组」。

封面的「⋯」可编辑说明、选中组内卡片或询问智能体。桌面上可将卡片和卡组拖到看板的间隙或末尾排序。拖动卡片到另一张未分组卡片的中间可建组，拖到已有卡组可归组。排序支持撤销和重做。把智能体推荐拖到「想尝试」空白处，或用卡片菜单收藏到主看板，推荐卡会追加到末尾。拖到「实践记录」空白处可预填实践。

多选卡片后可从「询问智能体」获取分组建议。聊天中可核对每组成员、修改目标名称并逐组确认。确认一次记为一步整理，可在成长看板撤销或重做。

「实践记录」按最近一次实践排序，领域用不同颜色和文字标识。「参考路径与任务」支持添加、编辑和删除主题，可从主题详情询问智能体，并编辑其任务草稿后保存到该主题。卡片菜单的「带到今日学习」会把卡片显示为「练习参考」。主题任务用「设为目标」，在同一位置显示为「当前学习目标」。两种内容都可在「今日学习」移除。完成番茄钟时，日志会相应添加「练习参考」或「目标」标签。

在智能体的「查找资料」里选「实践记录」，可按成果、实践说明或关联脚本中的关键词查找。找到对应日期的实践，点「复盘」在结果下方展开详情。点「复盘这次实践」会把该次备注和有限的关联摘录交给 DeepSeek，返回当时的做法、验证情况和可尝试的下一步。代码引用可定位到原文行号。

点「用作当前目标」可把建议带入目标表单，改写并确认后在「今日学习」查看。完成番茄钟时会把目标写入当日日志标签。[实践复盘验收](./GROWTH_ACCEPTANCE.md#对一次实践生成复盘)

## 项目代码

展开今日或历史日志的“项目代码”，选一个 UTF-8 的 `.cs` 文件保存快照，或粘贴指向具体提交的 GitHub 文件链接。可以同时保存同一版本的文件与链接。再次导入同名脚本会另建版本。“成长记录”中的“项目代码”入口可按项目查看版本、补充仓库地址及编辑版本资料。

在带行号的脚本快照里选中代码后，点选区旁的「询问智能体」，也可以在代码中右键。聊天框的 `</>` 可直接按脚本版本和行号选取。发送前可勾选附近上下文，确认后才会发送给 DeepSeek。只有 GitHub 链接的版本可以先在 GitHub 中查看，或补充本地快照后使用片段问答。

单击脚本中的一行可高亮并在右键菜单中询问。想了解文件在项目里的作用时，选「询问脚本用途」。发送前会显示本次使用完整正文还是首尾片段，以及是否附带保存的职责或版本说明。

在「项目代码」点「导入项目目录」，选择本地 Unity 项目根目录。预览相对路径，勾选需要保存的 UTF-8 `.cs` 文件，再创建项目或更新已有项目的目录快照。打开目录快照，可为目录或文件保存职责说明，并从脚本路径打开已有代码版本。[项目代码验收](./PROJECT_CODE_ACCEPTANCE.md)

在词条与实践的编辑表单中，可以从“关联资料”选择代码版本及其他相关资料，一起保存。阅读词条时可从“项目用例”打开版本。代码详情可回到对应的日志、词条和实践。仅保存 GitHub 链接时，通过已登录且有权限的浏览器查看文件。

## 数据备份与恢复

从「数据管理」导出完整备份。恢复采用整体替换，确认页面会显示备份内容和旧版备份缺少的资料。替换前可以先导出当前数据。[备份内容与兼容版本](./ARCHITECTURE.md#数据备份与恢复) · [组员验收步骤](./TEST_WORKSPACE_ACCEPTANCE.md#验收顺序)

## 统一检索

点击导航中的“检索”，可查学习日志的日期、正文、标签和知识点，词条的名称、别名、分类和正文，以及代码版本的项目名称、脚本路径和版本说明。用空格分隔多个关键词，结果会匹配每个词。结果按资料类型分组并高亮关键词。点击标题会跳到原资料的第一处可见命中，长日志有正文命中时自动展开。有编辑表单的目标页会在新标签打开，以保留原草稿。

在“代码版本”筛选中勾选“搜索脚本正文（本地快照）”，可按方法名等关键词查找保存的脚本内容。正文命中会显示行号，点开后滚动到该行并高亮关键词。只有 GitHub 固定链接的版本可按版本资料查找。

编辑词条或实践时，可在各类关联列表内筛选，已勾选的资料会随表单保存。定位与脚本搜索步骤见 [检索增强验收](./KNOWLEDGE_ACCEPTANCE.md#6-检索增强)。

## 关系视图

在今日或历史日志、词条、代码版本中点击“查看关系”，进入以该资料为中心的独立关系图。卡片颜色区分资料类型，点击卡片可打开原资料。已有直接关联默认标为“相关”。点选连线可填写短标签和补充说明，保存后可从两端查看。每组最多显示六条连线。验收步骤见 [关系视图验收](./KNOWLEDGE_ACCEPTANCE.md#7-关系视图)。

## 知识网络

从主导航打开“知识网络”。画布工具栏可搜索词条、日志和代码版本，切换图层、词条分类与一跳或两跳范围，以及进入全屏。右侧目录按词条分类展开。

在空白处按住左键拖动可平移画布，鼠标在画布内时按 Ctrl 滚动滚轮可围绕指针缩放。双击节点可打开原资料，拖动节点可临时移出原来的布局范围。“适应窗口”会把移动后的节点也纳入视野，“重置节点位置”可恢复自动排列。

在“图层与筛选”的“模块可见性”任意勾选词条分类，也可以在画布上右键模块标题，选择“隐藏此模块”或“仅显示此模块”。隐藏时该组词条与相连的线一起从画布隐藏。“只看跨模块关联”保留可见模块的词条，筛出模块之间的直接连线，以及至少两个可见模块直接关联的同一篇日志或同一代码版本。侧栏按模块对列出直接连线，点击结果可定位。打开原资料再在同一标签页返回，可继续原来的筛选、选中项、缩放和平移。见 [模块可见性与返回验收](./KNOWLEDGE_ACCEPTANCE.md#9-模块可见性与返回)。

拖动模块标题可移动整组，包括学习日志和代码版本。右键日志或代码的标题可隐藏整组，从“图层与筛选”恢复。右键词条可在图内编辑。右键词条模块标题可重命名分类或勾选成员移到其他分类。

按住 Shift 单击节点或从空白处框选，拖动任一选中节点即可一起移动。侧栏可批量改分类，也可“仅查看所选”以检查所选节点之间的直接连线。需要追溯间接关系时，勾选“显示中间节点（两跳）”。它会在当前筛选范围内补出没有直连的所选节点之间经过一个中间节点的路径。返回完整视图可继续原来的选中项、筛选、平移和缩放。

在“仅查看所选”中打开节点或连线详情后，单击画布空白处可回到所选节点，按住左键拖动仍可平移。在 Edge 中，全屏编辑弹窗打开时，短按 Esc 可关闭弹窗并留在全屏。

用画布工具栏或 Ctrl+Z 撤销移动、复位、分类变更及图内词条编辑，用 Ctrl+Shift+Z 重做。手动布局与撤销记录保留到当前标签页刷新或关闭。见 [整组移动与图内编辑验收](./KNOWLEDGE_ACCEPTANCE.md#10-整组移动多选与图内编辑)。

点连线图标进入连线模式，可以在图上点选起点和终点，也可以在各自的选择框里浏览或按关键词筛选。标签与说明可随连线一并保存，单击已有连线可编辑或移除。单击画布空白处可清除节点选择。空白处右键或点工具栏的加号可新建词条。

想用样例试操作时，可进入与个人数据隔离的测试工作区。[进入测试工作区](./SETUP.md#进入测试工作区) · [组员验收步骤](./TEST_WORKSPACE_ACCEPTANCE.md)
