# 测试工作区验收

在项目目录执行 `npm install`，再运行 `npm run dev -- --port 5185`。浏览器打开 [本地学习助手](http://localhost:5185)，点右下角「开发者工具」，选择「进入测试工作区」。新标签页从「今日学习」打开，页首显示「测试工作区」。

同一个浏览器会保留自己做过的测试修改。用开发者工具中的「恢复示例数据」可以重新开始。如果此前使用过知识网络演示，也可用这个操作加载新版样例。确认前可以取消。

| 功能 | 验收操作 |
| --- | --- |
| 今日学习 | 核对「检查预制体实例」日志和当前任务。用开发者工具模拟完成一次番茄钟，核对学习时长和日志标签。 |
| 历史日志与资料 | 打开 2026-10-05 的「在两个场景验证预制体引用」。检查示意图，并从关联资料打开「预制体」及 `PickupSpawner.cs`。 |
| 实践卡片 | 在「成长记录」打开「预制体与场景复用」卡组。查看两次实践和关联资料，再给「观察预制体实例的覆盖值」记录一次实践。 |
| 参考主题与任务 | 打开「预制体与场景复用」主题，试着完成「验证预制体更新会影响哪些实例」，回到今日学习核对目标变化。 |
| 回收站与备份 | 在「数据管理」分别查看「日志」「词条」「代码」中的样例并试着恢复。导出完整备份后，也可在测试工作区核对恢复结果。 |
| 智能体 | 从主题详情询问智能体，生成后尝试预填并保存一条任务。实际生成使用项目现有的 [DeepSeek 配置](../README.md#学习智能体)。 |
| 面板与隔离 | 拖动开发者工具标题栏，缩窄窗口检查操作是否可达。恢复示例时先取消一次，再确认恢复。最后从工具面板返回个人工作区，核对个人数据。 |
