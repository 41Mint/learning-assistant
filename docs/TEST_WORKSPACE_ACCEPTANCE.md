# 测试工作区验收

## 启动

安装 Node.js 24，从 GitHub 克隆仓库或下载并解压源码。在项目目录打开终端，依次运行以下命令。

```bash
npm ci
npm run dev -- --port 5185 --strictPort
```

保持终端运行，浏览器打开 [本地学习助手](http://localhost:5185)，点右下角「开发者工具」→「进入测试工作区」。新标签页从「今日学习」打开，页首显示「测试工作区」。组员可以直接验收本地功能。真实智能体生成需要单独完成 [DeepSeek 配置](./LOG_REVIEW_ACCEPTANCE.md#配置-deepseek)。

同一个浏览器会保留自己做过的测试修改。用开发者工具中的「恢复示例数据」可以重新开始。如果此前使用过知识网络演示，也可用这个操作加载新版样例。确认前可以取消。

### 启动时自动更新

1. 安装 Git 和 Node.js 24。从 GitHub 下载最新版 ZIP 并解压。已有 Git 克隆的组员更新一次即可在原项目目录找到启动文件。
2. Windows 双击 `start.bat`。macOS 在 Finder 双击 `start.command`。如果 macOS 提示确认打开下载的文件，请核对文件来自本仓库。[Apple 的打开说明](https://support.apple.com/en-us/102445)
3. 脚本会检查 `origin/master` 的更新，需要时安装依赖，再启动服务并用默认浏览器打开 `http://localhost:5185`。保留打开的终端窗口即可继续使用。继续在原来的浏览器访问即可查看原有记录。

从 ZIP 启动时，脚本第一次会在解压目录内建立 `learning-assistant-local` 更新副本。以后双击原来的启动文件即可。使用 DeepSeek 时，在这个更新副本中配置 `.env.local`。

更新前先关闭原来的开发服务。项目有本地代码修改、提交分叉或下载失败时，启动窗口会保留错误信息。也可以在项目目录运行 `npm run dev:latest` 使用同一流程。

## 验收顺序

| 功能 | 验收操作 | 预期结果 |
| --- | --- | --- |
| 今日学习 | 核对「检查预制体实例」日志和当前任务。用开发者工具模拟完成一次番茄钟，再在日志编辑器粘贴截图、保存并刷新。 | 增加 25 分钟，日志可查看本次学习的目标标签，截图刷新后仍可打开。 |
| 历史日志与资料 | 打开 2026-10-05 的「在两个场景验证预制体引用」，查看示意图，再从关联资料打开「预制体」及 `PickupSpawner.cs`。 | 图片可查看原图，词条和代码版本都能回到对应日志。 |
| 搜索与知识网络 | 检索「预制体」并打开词条。点「查看关系」追溯关联，再到「知识网络」搜索并定位词条。 | 检索结果可打开原资料，关系图显示关联，网络可定位同一词条。 |
| 实践卡片 | 从封面或「卡组」下拉打开「预制体与场景复用」。查看一张卡片并补记实践，再点带组名的返回链接。关闭弹窗后，从看板空白处框选卡片，用右键「移到卡组」选择「新建卡组…」，再试撤销、重做。 | 两个入口打开同一个卡组弹窗。详情返回后再次显示该组，补记保存在卡片中。撤销后卡片回原位，重做后恢复卡组。 |
| 参考主题与任务 | 打开「预制体与场景复用」主题，完成「验证预制体更新会影响哪些实例」，再回到今日学习。 | 完成数增加，已完成的任务从今日目标中清除。 |
| 回收站与备份 | 在「数据管理」从「日志」「词条」「代码」三个分类各恢复一个样例。导出完整备份，恢复示例数据，再导入刚才的备份。 | 恢复的资料可打开。导入后，之前的改动、图文、代码快照和关联一并找回。 |
| 智能体（选测） | 配置 DeepSeek 后，从主题详情询问智能体，生成后预填、修改并保存一条任务。 | 任务先以草稿展示，确认保存后才进入主题任务列表。 |
| 界面与隔离 | 在代码详情、词条目录和页面滚动查看样式。在日志中打开和取消「添加代码版本」。缩窄窗口检查导航和开发者工具。从工具面板返回个人工作区。 | 滚动条样式统一，表单平滑收起，窄屏操作可达，测试修改留在测试工作区。 |

## 任务关联与界面提示

1. 在「今日学习」的日志卡片点「关联任务」右侧的「选择任务」。展开后勾选「验证预制体更新会影响哪些实例」和「创建拾取物预制体」。保存后应显示两个可打开的任务。重新打开，取消勾选一项后点「收起任务」，两条关联应都保留。再次展开并点「添加任务」，选择所属主题后填写名称，点「保存任务并关联」，检查主题和日志两端的新任务。
2. 在「历史回顾」定位到 2026-10-05，将「在两个场景验证预制体引用」关联到「验证预制体更新会影响哪些实例」。点日志上的任务名称，页面应打开对应主题并定位任务。展开任务下方的「学习日志（2）」，点日期或标题可返回对应日志。改名或完成任务后，再从日志点开，关联仍应可用。
3. 在「数据管理」导出完整备份。解除一条任务关联，再恢复刚才的备份。日志和任务两端应重新出现该关联。若要验收删除，在测试工作区删除任务后回到原日志，应看到正文和其他任务关联仍可用。
4. 到「知识词条」创建两个不同分类的词条。打开第一个词条重新编辑，点分类输入框。下拉应贴着输入框显示两个分类，输入部分名称可筛选，方向键和 Enter 可以选择。直接填写一个新分类并保存也应生效。
5. 回到「今日学习」，检查番茄钟里的目标名称和「选择任务」或「查看任务」入口。给一篇日志加上标签，再从左侧「检索」切到「学习日志」，输入标签名。结果应显示匹配标签并可打开原日志。
6. 在「知识网络」的「图层与筛选」中检查「显示范围」。未选中节点时应显示选点提示。单击画布节点后可选一跳或两跳。勾选「只看跨模块关联」时显示关闭该选项的提示，进入连线模式时显示完成或取消连线的提示。
