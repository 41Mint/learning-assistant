   - **测试方法**：使用内联样式测试块确认 CSS 类缺失
   - **解决方案**：将图表渲染逻辑从 Tailwind 类改为内联样式
   - **修复内容**：
     - 柱状图容器、柱子、标签全部使用内联样式
     - 保留渐变效果、过渡动画、今日高亮

   - 原因：使用内联样式 `backgroundColor: '#ffffff'` 硬编码白色
   - 解决：改用 Tailwind 类名 `bg-white dark:bg-gray-800`
   - 教训：避免使用内联样式覆盖主题系统

2. **图表显示不明显**
   - 原因：基准线设置为 1 分钟，导致少量数据时柱子接近 100% 高度，视觉对比差
   - 解决：将基准线提升到 60 分钟，使图表比例更符合实际使用场景
   - 改进：添加过渡动画和更明显的最小高度（6px）

3. **TypeScript 编译警告**
   - 原因：导入了未使用的 store 变量
   - 解决：移除 `currentLog` 和 `updateStreak` 的解构
   - 教训：定期运行构建检查代码质量

4. **图表完全无法显示（关键问题）**
   - 原因：Tailwind 的生产构建 CSS 中完全缺失颜色类
   - 深层原因：动态类名（如模板字符串拼接的 `bg-${color}-500`）在 JIT 模式下不会被扫描
   - 解决：改用内联样式 `style={{ backgroundColor: ... }}`
   - 教训：Tailwind JIT 只识别完整的静态类名，动态类名必须用 safelist 或内联样式
