# 日志整理建议 v1

## 配置 DeepSeek

1. 登录 [DeepSeek 开放平台](https://platform.deepseek.com/api_keys)，创建一个 API Key，确认 API 账户有可用余额。
2. 在项目根目录运行 `Copy-Item .env.example .env.local`。如果已有 `.env.local`，直接打开它并补充下面两行。

   ```dotenv
   DEEPSEEK_API_KEY=在这里粘贴你的密钥
   DEEPSEEK_MODEL=deepseek-flash
   ```

   密钥只填在本机的 `.env.local`。该文件已被 Git 忽略，服务端读取密钥，浏览器和备份中没有密钥。模型默认为 `deepseek-flash`，可按 [DeepSeek 官方 API 文档](https://api-docs.deepseek.com/) 修改。
3. 在原来运行服务的终端按 Ctrl+C 停止服务，再运行 `npm run dev -- --port 5185 --strictPort`，打开 [本地学习助手](http://localhost:5185/)。
4. 打开一篇日志的编辑表单，单击浮动的学习智能体图标，点「生成整理建议」。点击后，当前 Markdown 文字、可选整理范围及查询到的有限资料元数据会发送到 DeepSeek。图片二进制、其他日志正文和项目脚本正文留在本地。一次整理通常有两次模型调用。发布版可用 `npm run build` 和 `npm run preview -- --port 5185 --strictPort` 在本机演示。

## 验收用例

| 场景 | 输入与操作 | 预期 |
| --- | --- | --- |
| 正常整理 | 用 Day1 日志，准备已有词条「像素单位」，别名为 PPU。生成建议，检查原文依据。勾选一条标签、一项词条建议，再按日志保存。 | 能看到检索词与本地命中。可复用已有词条；新词条先显示名称、分类和正文草稿。仅采纳勾选项，原有标签和关联保留。 |
| 临场改变要求 | 填「只整理 Tilemap 相关内容」后重新生成。 | 查询和建议按新范围调整。上一批勾选清除。若之后改动正文，重新生成或取消勾选即可保存。 |
| 资料不足或失败 | 在测试日志只写「今天看了教程」；另试断开网络后生成，再恢复网络。 | 资料不足时可以无建议。调用失败有提示，可以重试或照常保存日志。 |

自动测试通过模拟整理接口检查流程、查询结果、校验与持久化。真实模型返回和延迟应在配置密钥后按上表记录。若出现密钥无效、余额不足或限流，页面会显示对应原因。超过 24,000 字符的正文只分析开头，界面会提示。

## 浮动入口与窄屏导航

1. 编辑一篇日志，拖动智能体图标到屏幕另一处。松手后图标停在新位置。刷新可检查图标位置，随后重新打开日志编辑。
2. 点图标，切到「日志整理」并生成建议。建议列表只显示标题和勾选框。点「详情」切换到该建议，查看原文和修改草稿，再点「返回建议」。勾选一项，关闭窗口后再打开，核对选中项仍在。
3. 切换到「成长记录」，核对当前日志的建议已隐藏。回到原编辑页，切到「日志整理」，确认此前勾选仍在。点「返回日志」并保存，核对实际采纳结果。
4. 把窗口缩窄至 720 像素及以下。顶部显示当前页面和检索。点击当前页面的菜单按钮，核对导航浮在正文上方。选择页面、点外部或按 Esc 都可收起菜单。智能体在这个宽度下从底部打开。

## 浮动窗口与自由问答

1. 在桌面打开智能体，拖标题栏移动，拖右下角调整大小。也可用键盘聚焦右下角手柄，再按方向键调整。窗口打开时，仍可点击未被遮住的页面区域和导航。
2. 右键图标或标题栏，或点窗口内的「…」。试「靠左」「靠右」「恢复默认位置和大小」。再移动和缩放一次，关闭重开和刷新页面，核对保存的窗口位置及尺寸。把窗口缩窄到 720 像素及以下应改用底部抽屉，恢复桌面宽度后可继续使用原位置。
3. 打开「自由问答」，输入「PPU 是什么？」并发送，再追问「能举个例子吗？」。关闭窗口或切换页面再打开，检查对话仍在。刷新页面会开始新会话。
4. 编辑 Day1 日志，在问答栏勾选「引用当前日志」，确认日期和「草稿」标记。给正文加一句未保存的内容，再问「我最后补充的这一句是什么意思？」。切换到另一页面后，引用选项应清除。回到原日志整理页，检查已勾选的建议和正文草稿。
5. 发送一条问题后点「停止」，或暂时断网测试失败。输入应保留，可修改后再次发送。

问答沿用现有 DeepSeek 本机配置。发送问题时携带最近四轮同类对话，引用日志的追问按日志 ID 分组。仅勾选引用时附带该篇日志文字。问答记录留在当前页面会话内，不写入日志或备份。
