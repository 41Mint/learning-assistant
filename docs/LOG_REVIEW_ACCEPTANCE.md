# 学习智能体验收

## 配置 DeepSeek

真实模型用例需先 [配置 DeepSeek 并重启本地服务](./SETUP.md#配置-deepseek)。

打开一篇日志的编辑表单，点浮动的学习智能体图标，发送「整理这篇日志，提炼可以复用的知识」，或直接点「生成整理建议」。生成会把当前 Markdown、整理范围和有限的资料元数据发送给 DeepSeek。图片二进制、其他日志正文和项目脚本正文留在本地。

## 验收用例

| 场景 | 输入与操作 | 预期 |
| --- | --- | --- |
| 正常整理 | 用 Day1 日志，准备已有词条「像素单位」，别名为 PPU。生成建议，检查原文依据。勾选一条标签、一项词条建议，再按日志保存。 | 能看到检索词与本地命中。可复用已有词条；新词条先显示名称、分类和正文草稿。仅采纳勾选项，原有标签和关联保留。 |
| 对话中修订 | 生成建议后输入「把第 2 条的名称缩短」。再按编号或名称要求保存。也可展开建议核对修改。 | 草稿针对所指条目和字段更新。编辑中的日志随正文一起保存。 |
| 调整整理范围 | 发「重新整理，只提取 Tilemap 相关内容」。 | 查询和建议按新范围调整，上一批勾选清除。正文改变后可以重新生成，或取消勾选后继续保存正文。 |
| 资料不足或失败 | 在测试日志只写「今天看了教程」；另试断开网络后生成，再恢复网络。 | 资料不足时可以无建议。调用失败有提示，可以重试或照常保存日志。 |

自动回归通过模拟接口覆盖查询、草稿校验、保存与失败流程。真实模型返回和延迟应在配置密钥后按上表记录。若出现密钥无效、余额不足或限流，页面会显示对应原因。超过 24,000 字符的正文只分析开头，界面会提示。[学习智能体用例](../tests/log-review.spec.ts)

## 浮动入口与窄屏导航

1. 编辑一篇日志，拖动智能体图标到屏幕另一处。松手后图标停在新位置。刷新可检查图标位置，随后重新打开日志编辑。
2. 打开智能体并生成整理建议。点击卡片查看依据和草稿，试用右键「引用这条建议继续询问」。有可管理的草稿时展开「管理建议」，试全选、调整单条勾选和编辑字段。
3. 关闭窗口后重开，核对建议和草稿仍在。点击面板上方「返回日志」，保存后核对实际采纳结果。
4. 把窗口缩窄至 720 像素及以下。顶部显示当前页面和检索。点击页面菜单，核对导航从左侧打开。选择具体页面、点抽屉外侧或按 Esc 都可收起菜单。智能体在这个宽度下从底部打开。

## 浮动窗口与自由问答

1. 在桌面打开智能体，拖标题栏移动，拖右下角调整大小。也可用键盘聚焦右下角手柄，再按方向键调整。窗口打开时，仍可点击未被遮住的页面区域和导航。
2. 右键图标或标题栏，或点窗口内的「…」。试「靠左」「靠右」「恢复默认位置和大小」。再移动和缩放一次，关闭重开和刷新页面，核对保存的窗口位置及尺寸。把窗口缩窄到 720 像素及以下应改用底部抽屉，恢复桌面宽度后可继续使用原位置。
3. 在输入框发送「PPU 是什么？」，再追问「能举个例子吗？」。如果窗口正显示整理日志、查找资料等工具，从「试试这样问」选择「退出当前情境」，回到问答后再发送问题。关闭窗口或切换页面再打开，检查对话仍在。刷新页面会开始新会话。
4. 编辑 Day1 日志，在问答栏勾选「引用当前日志」，确认日期和「草稿」标记。给正文加一句未保存的内容，再问「我最后补充的这一句是什么意思？」。切换到另一页面后，引用选项应清除。回到原日志整理页，检查已勾选的建议和正文草稿。
5. 发送一条问题后点「停止」，或暂时断网测试失败。输入应保留，可修改后再次发送。

问答沿用现有 DeepSeek 本机配置。发送问题时携带最近四轮同类对话，引用日志的追问按日志 ID 分组。仅勾选引用时附带该篇日志文字。问答记录留在当前页面会话内，不写入日志或备份。

## 最小化与常驻工具

1. 从「成长记录」打开智能体，在问答框输入一行文字，点标题栏的「−」。在窄屏再试一次。最小化时可继续操作页面，点浮动图标会恢复原内容。
2. 发送「帮我整理 11-5 的日志」。同月同日有多篇时，可输入完整日期或在匹配结果中选择。选中后可在窗口内继续生成、修改和保存建议。
3. 发送「打开 PPU 词条」。点对应结果，核对词条详情及命中高亮。智能体会最小化以让出页面。若词条页有未保存的编辑，结果应在新标签页打开，原草稿仍在。没有匹配结果时，可继续输入关键词。

日期和关键词查找在本地完成。「试试这样问」里的建议也会作为一条消息送出。组内智能体推荐的保存路径见[卡组与收藏练习](./GROWTH_ACCEPTANCE.md#卡组与收藏练习)。
