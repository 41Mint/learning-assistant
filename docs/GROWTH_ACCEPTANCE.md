# 成长记录验收

以下步骤用于回归实践记录、待尝试练习、练习推荐和卡组操作。[成长记录用例](../tests/growth.spec.ts) · [卡组与样例用例](../tests/test-workspace.spec.ts)

使用 [本地预览](http://localhost:5185/#path)。可以选已有的 Day1 图文日志和一个词条测试关联。

1. 打开「想尝试」，右键「用 Tilemap 画出一段地面」，点「我做到了」。把实践日期设为 Day1 的实际日期，填一行说明并选关联日志和词条。保存后确认卡片进入「实践记录」，点标题查看历次实践和资料链接。
2. 通过「返回卡片」回到网格，打开成果卡片的菜单，点「追加实践」。填另一段说明并保存。确认两次实践留在同一张卡片里，最近日期排在前面。刷新后检查日期、说明和资料链接。编辑或删除其中一次实践，再回看另一次实践及原资料。
3. 从「想尝试」记录「让角色左右移动并停下来」。分别选择 Unity 和 C# 筛选，两边都应显示这项成果。也可以点击「记录自定义成果」，只填写名称和实践日期后保存。
4. 切到“参考路径与任务”，从主题列表选择节点，查看完成标记和任务。即使 C# 基础尚未标记完成，也可以在 Unity 节点点“添加任务”，填写后保存，或选择当前目标。回到“今日学习”点击“清除当前目标”，确认可以直接开始计时。
5. 在“数据管理”导出完整备份。用 Edge InPrivate 窗口打开同一地址并恢复该文件，检查摘要中的成果及实践数量。恢复后打开成长记录，确认资料链接仍能跳转。若选择 v3 备份，摘要会提示该文件缺少成长记录。

手测时尤其关注从教程结束到记录第一项成果需要多少操作，以及按领域回顾时能否迅速找到先前做过的事。

## 智能体回看实践与代码问答

1. 准备一项已保存的实践，在「关联资料」中选择一份本地脚本快照，按需加上日志或词条。从任意页面打开智能体，点「回看实践」，或在问答里输入「上次我怎么实现角色移动的？」并将关键词换成你的实践主题。
2. 选择一次实践，核对日期、说明和关联资料。点「打开原实践」或脚本链接，确认定位到选定记录。也可以用脚本里的方法名再搜一次，查看关联版本的命中行。智能体缩回图标后可点开继续浏览。
3. 点「设为当前目标」，将预填名称改成这次要做的具体动作，确认后到「今日学习」查看。可正常开始计时，也可通过开发者工具模拟一次番茄钟完成，再到今日日志查看目标标签。
4. 打开本地脚本快照，左键单击一行，确认行号和整行背景高亮。在该行右键，从「询问智能体」下选择「询问当前行」，核对聊天框中的行号。选中几行时，可使用选区旁的快捷按钮，或在选区内右键选择「询问所选代码」。
5. 勾选「附带上下文」后可发送同一快照前后各最多 5 行，实际范围显示在选项旁。也可直接从聊天输入框旁的 `</>` 选择脚本和行号，核对预览后引用。移除片段可恢复普通问答。发送沿用现有 DeepSeek 配置。
6. 用空白浏览器工作区首次打开助手，或发送「你能做什么」。点入门卡片，确认直接进入写日志、记录实践或保存代码的表单。已有资料的工作区会给出可以立即使用的整理、回看和代码问答入口。
7. 点脚本快照旁的「询问脚本用途」，或在右键菜单及聊天框的代码选择器中选同一操作。先核对发送范围，再问「这个脚本在项目中负责什么？」。最多 24,000 字符的脚本发送完整正文，超过时会注明只发送首尾片段。若已填写对应目录或脚本职责说明，也会随请求发送。
8. 收到脚本用途的回答后，切换到一行或一段代码。确认「这段代码是做什么的？」在当前引用和输入框之间，点一下即可填入并继续编辑。
9. 右键代码行，将鼠标移到「询问脚本用途」，确认只有悬停的选项高亮。点击菜单外、滚动代码或页面、切换页面以及按 Esc 都可收起菜单。用 Tab 聚焦代码预览，按 Shift+F10 打开菜单，确认键盘焦点提示留在选项内部。

## 成长视图与练习推荐

1. 桌面检查顶栏的站点图标和当前页名。将鼠标移到下方的左侧图标栏，检查侧栏覆盖展开，正文位置和宽度保持稳定。用 Tab 聚焦导航也可展开。窄屏或纯触屏从「页面菜单」打开抽屉。
2. 在「想尝试」选一个领域，从「添加练习」选择「让智能体推荐」。确认原页面保留，浮动智能体切到「推荐练习」，并带入已选领域。输入可选偏好，点「生成练习建议」，检查结果卡片的验证方法和资料依据。推荐沿用 DeepSeek 配置。最小化窗口即可继续浏览内置练习。
3. 改一下偏好并点「换一批」，核对新建议。在卡片菜单点「我做到了」，确认成果名称和关联资料已预填。保存后应在「实践记录」定位到本次实践。
4. 切到其他页面，在智能体工具栏点「推荐练习」，或在问答输入「帮我推荐几个练习」。确认页面地址保持原样，先前的偏好和结果仍在同一个智能体窗口。
5. 在任意卡片右键或点「⋯」，选择「带到今日学习」。在「今日学习」核对卡片标题及「练习参考」，再移除参考。另选一个主题任务设为目标，核对「当前学习目标」。返回卡片，选「询问智能体」，检查引用标题和快捷问题。发送后检查回答能否解释验证方法或给出一个起步步骤。

## 卡组与收藏练习

1. 在「实践记录」的卡片菜单选择「编辑实践」或「删除实践」。同一张卡有多次实践时，用日期和说明选择对应记录。删除后提示约 3 秒消失。点卡片标题仍可查看历史。
2. 从「想尝试」打开智能体并生成推荐，在一张推荐卡片的「⋯」选「加入『想尝试』」。关闭智能体或刷新，点已加入的卡片标题，核对验证方法与来源。再打开「我做到了」，确认日志、词条和代码引用按推荐来源预选。
3. 核对看板上的「卡组」下拉和「新建卡组」等高，依次排在领域筛选之后。创建一个卡组，从两张卡片的菜单选择「移到卡组」。分别点卡组封面和「卡组」下拉，确认进入同一个有组名的弹窗。查看一张卡片，用带组名的返回链接回到该组，再用浏览器后退和前进检查同一条路径。
4. 在「管理卡组」改名，在全局检索选「实践卡片与卡组」，以新组名或成员标题搜索。点组名打开弹窗，点组内卡片结果在弹窗里定位。完成组内一张练习后，弹窗按「实践记录」和「想尝试」分组。只有同类卡片时直接显示卡片。
5. 导出备份并在独立浏览器窗口恢复，确认卡组与收藏保留。删除卡组后，可在各自的看板找到原成员。也可在卡片菜单选择「移到卡组」→「未分组」，单独移出一张。
6. 编辑练习卡片，勾选常用领域并输入「输入系统」。按 Enter 加入后，再填写一个自定义领域并直接保存。刷新后从「按领域筛选」选择新名称，打开卡片点「我做到了」，检查领域是否带入实践。
7. 展开卡组弹窗中的「组内操作」，按领域筛选，核对「记录自定义成果」位于「添加练习」左侧。桌面悬停「添加练习」时，等高的面板向右展开「自己填写」和「让智能体推荐」，移开后收起。缩窄窗口后点击按钮，或 Tab 后按 Enter，也能选择这两项。按 Esc 先关闭选项，再按 Esc 关闭卡组。
8. 在组里自己填写练习或记录自定义成果。保存后卡片归入当前卡组，详情回到同一弹窗。配置 DeepSeek 后可选「让智能体推荐」，确认带入组名和已选领域。从建议卡片的「⋯」选「加入此卡组」，关闭智能体后可在原卡组找到卡片。用旧的 `#path?group=组ID&view=all` 地址也可以打开弹窗。

### 卡组预览与拖拽

1. 分别打开「实践记录」和「想尝试」。只含一种状态的卡组应出现在对应看板。混合卡组在两个看板上的封面都显示组内总张数。切换领域筛选检查封面是否出现，点开封面可核对总数。单击和 Shift 单击封面都在当前页面打开卡组浮层，点击外部或按 Esc 关闭。
2. 在桌面拖动卡片，确认卡片跟随鼠标。拖到两张卡片之间应出现插入标记，松手后原位置由其它卡片依次补齐。拖到网格末尾的空位应追加到最后。核对撤销、重做和刷新。拖到另一张卡片的中间，输入组名并保存。把第三张卡拖入该卡组，再从空白处右键选择「撤销整理」，确认第三张回到原处。
3. 把未收藏的推荐拖到「想尝试」看板任意空白处。检查收藏后的详情及来源。拖到「实践记录」的空白处时应打开预填实践，分别检查取消和保存。也可拖到单张卡上创建卡组，或拖进已有卡组，把推荐收藏到组内的「想尝试」。触屏或键盘可使用卡片菜单。
4. 右键卡组，尝试打开、重命名和删除。删除弹窗与删除实践样式一致，确认删除后原成员应回到各自的看板。右键看板空白处，检查新增、智能体推荐和新建卡组入口。

### 卡组移出和问答

1. 打开卡组，在一张卡片上右键选择「移出当前卡组」。确认浮层中少了这张卡，关闭浮层后可在对应状态的看板找到它。点「撤销整理」将它放回原组。
2. 在桌面把同一张卡拖到浮层外的背景，确认背景变亮，松手后卡片移出。在浮层内松手或按 Esc 取消时，卡片仍在组内。
3. 在同时含有实践记录和练习卡片的卡组上右键，点「询问智能体」。检查输入框旁的卡组引用和快捷问题。发送后核对组名建议和分类理由是否对应具体成员。问答沿用现有 DeepSeek 配置，卡组名称和归属可继续手动修改。

### 卡片多选与整理历史

1. 单击卡面选中一张，按住 Shift 点击另一张来加选。桌面上可从看板或卡组内空白处按住左键拖动框选，按住 Shift 框选可追加。键盘聚焦卡面后可用空格和 Shift 加空格。点击标题可进入详情。
2. 选中两张或更多卡片后，右键卡面或点「⋯」，确认菜单标题显示选中张数。点「移到卡组」并确认，打开目标卡组核对选中的卡片全部移入。在卡组内多选时，也可一起移出卡组。在「想尝试」中试用批量「移出『想尝试』」。
3. 从多选菜单或选区工具栏点「询问智能体」，核对聊天框直接引用整个选区。点「这些卡片可以怎么分组？」后发送，核对回答所用成员。单选时保留原有的单卡问答。
4. 在看板或卡组浮层用撤销、重做图标检查整理历史。`Ctrl+Z` 撤销，`Ctrl+Shift+Z` 或 `Ctrl+Y` 重做。一次批量操作对应一步，连续操作可逐步恢复。进入输入框时，撤销键仍按输入框的规则工作。

### 参考主题维护与智能体任务草稿

1. 打开「成长记录 → 参考路径与任务」，添加主题并填写名称、领域、说明。可在「可参考的主题」里关联其他主题。编辑一个已有任务的主题，检查原任务和完成状态仍在，重新加载后确认修改已保存。
2. 从主题详情点「询问智能体」，选择「这个主题从哪里开始？」或「帮我拆成小任务」并发送。使用现有 DeepSeek 配置，核对建议里每项任务的操作与完成条件。
3. 点某条建议的「添加为任务」，修改名称或说明后保存。也可试用取消，检查任务列表。切换到另一主题后从聊天打开原建议，确认保存表单仍指向原主题。
4. 导出完整备份后，试删带有任务的主题。核对确认框中的任务数，确认删除后检查其任务、完成标记和引用是否已移除。若当前目标属于该主题，检查「今日学习」中的目标。用独立浏览器恢复备份可找回删除前的主题与任务。

### 智能体分组建议

1. 选中几张主题相近的卡片，经「询问智能体」发送「这些卡片可以怎么分组？」。回复中的建议会列出名称、理由、卡片和当前归属。
2. 点「应用这组」，核对将移入的卡片和目标名称。可修改名称，输入已有组名时会加入该组。点「取消」后核对卡片归属。
3. 任选一组点「确认应用」，在看板中核对这组成员的位置。再使用整理的撤销、重做按钮，确认一次应用对应一步整理。

### 卡片布局与删除回归

1. 在桌面宽度打开「想尝试」，收藏一张带验证方法和来源的推荐卡，确认同一行的其他卡片宽高保持稳定。
2. 对收藏卡选择「我做到了」并保存。观察「实践记录」中卡片上的练习摘要，点标题核对完整说明和验证方法。
3. 从「实践记录」的卡片菜单删除最后一次实践。确认删除框关闭，卡片回到「想尝试」。再次记录实践后应直接显示结果。随后从详情页删除这次实践，确认使用同样的弹窗、提示和返回行为。

### 手动添加及编辑卡片

1. 在「想尝试」点「添加练习 → 自己填写」，填名称、说明及可选验证方法。保存后点标题或刷新原详情地址，核对内容。通过详情或「⋯」编辑说明。
2. 在一个内置卡片的「⋯」选择「移出『想尝试』」，刷新确认已移出，再用「恢复内置练习」找回。自建及推荐卡片也可以从菜单移出。
3. 从「实践记录」记录自定义成果，填写「卡片说明」和「这次做了什么」。保存后核对详情中的说明和本次实践，返回列表检查卡面摘要。
