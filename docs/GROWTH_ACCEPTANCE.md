# 成长记录 v1 验收指南

自动验证和用户验收均已通过。以下步骤可用于回归检查。

使用 [本地预览](http://localhost:5185/#path)。可以选已有的 Day1 图文日志和一个词条测试关联。

1. 打开“可以尝试”，在“用 Tilemap 画出一段地面”上点“我做到了”。把实践日期设为 Day1 的实际日期，填一行说明。展开“关联学习日志”和“关联知识词条”，各勾选一项，再点“保存实践”。确认“最近做到”出现成果卡片，点击卡片里的链接能返回正确日志和词条。
2. 回到成果卡片点“追加实践”，填另一段说明并保存。确认两次实践留在同一张卡片里，最近日期排在前面。刷新后检查日期、说明和资料链接。编辑或删除其中一次实践，再回看另一次实践及原资料。
3. 从“可以尝试”记录“让角色左右移动并停下来”。分别选择 Unity 和 C# 筛选，两边都应显示这项成果。也可以点击“记录自定义成果”，只填写名称和实践日期后保存。
4. 展开“参考路径与任务”，查看旧节点完成标记和任务。即使 C# 基础尚未标记完成，也可以在 Unity 节点添加任务或选择当前目标。回到“今日学习”点击“清除当前目标”，确认可以直接开始计时。
5. 在“数据管理”导出完整备份。用 Edge InPrivate 窗口打开同一地址并恢复该文件，检查摘要中的成果及实践数量。恢复后打开成长记录，确认资料链接仍能跳转。若选择 v3 备份，摘要会提示该文件缺少成长记录。

手测时尤其关注从教程结束到记录第一项成果需要多少操作，以及按领域回顾时能否迅速找到先前做过的事。
