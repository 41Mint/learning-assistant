# 知识词条 v1：规格与验收步骤

状态：自动验证及用户验收通过（2026-11-05）。以下步骤保留用于后续回归。

## 目标与范围

从“按天记录和补充”扩展为“围绕一个知识点持续整理，并找回多天的学习情境”。词条可独立存在，只需名称；别名、单层分类和 Markdown 正文可逐步补充。日志与词条为多对多关系，附可选说明；词条之间仅提供手动、双向的“相关”。

验收条件：创建/编辑后刷新仍保留；按名称/别名和分类找到词条；从日志创建或关联词条并回到原日期；多天关联与改名不破坏关系；解除/删除不影响原日志；新版备份完整恢复，旧版仍接受，错误数据与存储失败不破坏原数据。

可逐步将旧知识点手动关联到词条。目录按名称和别名筛选，顶部“检索”也可查找词条正文。自动测试使用隔离浏览器，以下步骤用于确认真实资料下的体验。

## 1. 从 Day1 建立词条

1. 打开 [本地预览](http://localhost:5185/)，先到“数据管理”导出一份当前完整备份。
2. 切到“历史回顾”，定位 `2026-11-05` 的 Day1 笔记（若导入时用了其他日期，以实际日期为准）。已有内容无需再次导入。
3. 在“关联知识词条”展开“关联已有词条 / 新建词条”。“关联说明”填“初次接触，见 PPU 小节”，“新词条名称”填 `PPU`，点“新建并关联”。已有同名词条时用上方下拉框关联。
4. 预期：该日志出现可点击的 `PPU` 及说明，原正文、截图、标签与时长不变。再创建/关联 `Sprite 切割`，同一日志应出现两个词条。
5. 若日志已有旧知识点，表单下方会提供“创建并关联/关联已有”的快捷按钮。点击后原知识点文字仍保留，不会自动转换其他文字。

## 2. 补充、查找与改名

1. 点击日志中的 `PPU`，进入词条页。点“编辑词条”，别名填 `Pixels Per Unit，像素单位`，分类填 `2D 素材`。
2. 正文可填：`## 我的理解`，下一段填“16 像素宽的图，在 16 PPU 时宽 1 个世界单位。”确认 Markdown 预览后保存。
3. 预期：“相关学习记录”中显示 Day1 日期及刚才的说明；点击日期应返回 Day1，日历月份也对应。再从日志回到词条。
4. 在目录搜索 `pixels`，预期仍能找到 PPU；切换分类应过滤列表。清空搜索或点“全部”恢复列表。
5. 将名称改为 `Pixels Per Unit`、别名保留 `PPU` 后保存；回到原日志，预期关联名称同步更新。刷新仍能保留词条和关联。
6. 测试重名：新建另一个词条，将名称或别名填为已有的 `PPU`。预期提示重复且不覆盖原词条；取消编辑即可。

## 3. 多天情境与相关词条

1. 在另一条已有日志（也可用今日记录）的“关联知识词条”中选择刚才的词条，填不同的说明，如“第二次比较：32×32 素材”。点“关联选中词条 / 更新说明”。
2. 打开该词条，预期“相关学习记录”同时列出两天，说明各自独立；重复关联同一日志不会增加重复项。重新选择已有词条可更新这一天的说明。
3. 点“编辑词条”，在“关联资料（可选）”中展开“关联其他词条”，勾选 `Sprite 切割` 并保存。点击保存后的链接，确认另一词条也能指回 PPU。同一表单还可选择学习日志和已保存的代码版本。
4. 在编辑表单取消勾选一项后先点“取消词条编辑”，确认原关联仍在。再次取消勾选并保存，确认双方都移除这条关系。列表不会提供自己。
5. 在日志中解除一个词条关联，预期只移除该日志与词条的链接，原日志和词条都保留。
6. 可新建一个“测试词条”并关联日志/其他词条，确认删除它。预期只清除该词条及其关系，日志原文、图片和其他词条不变。

## 4. 备份恢复与原有功能

1. 到“数据管理”导出完整备份。预期下载 JSON，提示包含词条；选择该文件后，摘要列出词条数、日志关联数和词条间关联数，先点“取消”检查无修改。
2. 打开 Edge InPrivate 窗口（Ctrl+Shift+N），访问同一地址，在“数据管理”选择该备份。核对摘要后点“确认恢复并刷新”。
3. 在独立窗口确认：词条正文、别名、分类、两天的关联说明、相关词条与原日志图片都可读取；词条日期链接返回正确日志。正常窗口数据不受影响。
4. 若有以前的 v1/v2 备份，可在独立窗口选择文件检查摘要。预期提示旧备份不含知识词条；确认恢复后词条为空，这是整体替换的结果。不要在正常窗口为测试覆盖当前数据。
5. 在正常窗口进入今日编辑或词条编辑，填入草稿后切换入口再回来；预期草稿保留。保存后刷新才应保留，未保存草稿不保证刷新后保留。
6. 启动番茄钟后切换入口，预期计时继续；今日/历史图文、展开收起及学习曲线仍可用。

## 5. 关联排版与检索

1. 打开已有词条并点击“编辑词条”，展开关联学习日志、其他词条、代码版本。勾选框应在左侧、文字紧随其后，长路径在列表内换行。缩窄浏览器后再检查一次。
2. 在“关联学习日志”中输入一篇笔记的日期或关键词，勾选匹配项。换成无关关键词后再清空，确认勾选仍在。确认后保存词条，或取消以保留原资料。
3. 从任意入口点顶部“检索”，输入一条已有的关键词，例如 `Tilemap` 或 `InputManager.cs`。结果按资料类型分组，可点击类型缩小范围。点击结果标题，核对原日志日期、词条或代码版本。
4. 若目标页有打开的编辑表单，检索结果会在新标签页打开。返回原标签页并回到编辑入口，确认草稿内容仍在。

## 6. 检索增强

1. 点顶部“检索”，输入一个只在长日志后半段出现的词。导入过 Day1 笔记时可用“后续随使用补充”。确认结果片段标亮该词，点击标题后日志自动展开并滚到高亮处。
2. 搜索一个词条别名或日志标签，点开后检查对应字段的高亮。通过顶部普通入口回到阅读页，浏览器后退可重新打开带定位的结果。可见的正文、标签和资料字段可定位，Markdown 隐藏的链接地址可在结果片段中核对。
3. 在“检索”中选择“代码版本”，勾选“搜索脚本正文（本地快照）”。若已导入 Whack-a-Mole 的 `InputManager.cs` 快照，可搜 `ScreenToWorldPoint`。确认结果显示版本、行号与关键词，点击后脚本预览滚到命中行，C# 语法颜色仍在。只有 GitHub 固定链接的版本可用路径或版本说明查找。

## 反馈重点

请优先反馈：从日志创建词条是否顺手；词条中原日志列表及说明能否帮助找回情境；分类和别名是否够用。概念之间若需要更具体关系，给出真实的一对概念及使用场景，再评估扩展。
