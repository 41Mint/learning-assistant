# 知识词条 v1：规格与验收步骤

状态：自动验证及用户验收通过（2026-11-05）。以下步骤保留用于后续回归。

## 目标与范围

从“按天记录和补充”扩展为“围绕一个知识点持续整理，并找回多天的学习情境”。词条可独立存在，只需名称；别名、单层分类和 Markdown 正文可逐步补充。日志与词条为多对多关系，附可选说明；词条之间仅提供手动、双向的“相关”。

验收条件：创建/编辑后刷新仍保留；按名称/别名和分类找到词条；从日志创建或关联词条并回到原日期；多天关联与改名不破坏关系；解除/删除不影响原日志；新版备份完整恢复，旧版仍接受，错误数据与存储失败不破坏原数据。

可逐步将旧知识点手动关联到词条。目录按名称和别名筛选，顶部“检索”也可查找词条正文。自动测试使用隔离浏览器，以下步骤用于确认真实资料下的体验。

## 1. 从 Day1 建立词条

1. 打开 [本地预览](http://localhost:5185/)，先到“数据管理”导出一份当前完整备份。
2. 切到“历史回顾”，定位 `2026-11-05` 的 Day1 笔记（若导入时用了其他日期，以实际日期为准）。已有内容无需再次导入。
3. 在“关联知识词条”展开“关联已有词条 / 新建词条”。“关联说明”填“初次接触，见 PPU 小节”，“新词条名称”填 `PPU`，点“新建并关联”。已有同名词条时用上方下拉框关联。
4. 预期：该日志出现可点击的 `PPU` 及说明，原正文、截图、标签与时长不变。再创建/关联 `Sprite 切割`，同一日志应出现两个词条。
5. 若日志已有旧知识点，表单下方会提供“创建并关联/关联已有”的快捷按钮。点击后原知识点文字仍保留，不会自动转换其他文字。

## 2. 补充、查找与改名

1. 点击日志中的 `PPU`，进入词条页。点“编辑词条”，别名填 `Pixels Per Unit，像素单位`，分类填 `2D 素材`。
2. 正文可填：`## 我的理解`，下一段填“16 像素宽的图，在 16 PPU 时宽 1 个世界单位。”确认 Markdown 预览后保存。
3. 预期：“相关学习记录”中显示 Day1 日期及刚才的说明；点击日期应返回 Day1，日历月份也对应。再从日志回到词条。
4. 在目录搜索 `pixels`，预期仍能找到 PPU；切换分类应过滤列表。清空搜索或点“全部”恢复列表。
5. 将名称改为 `Pixels Per Unit`、别名保留 `PPU` 后保存；回到原日志，预期关联名称同步更新。刷新仍能保留词条和关联。
6. 测试重名：新建另一个词条，将名称或别名填为已有的 `PPU`。预期提示重复且不覆盖原词条；取消编辑即可。

## 3. 多天情境与相关词条

1. 在另一条已有日志（也可用今日记录）的“关联知识词条”中选择刚才的词条，填不同的说明，如“第二次比较：32×32 素材”。点“关联选中词条 / 更新说明”。
2. 打开该词条，预期“相关学习记录”同时列出两天，说明各自独立；重复关联同一日志不会增加重复项。重新选择已有词条可更新这一天的说明。
3. 点“编辑词条”，在“关联资料（可选）”中展开“关联其他词条”，勾选 `Sprite 切割` 并保存。点击保存后的链接，确认另一词条也能指回 PPU。同一表单还可选择学习日志和已保存的代码版本。
4. 在编辑表单取消勾选一项后先点“取消词条编辑”，确认原关联仍在。再次取消勾选并保存，确认双方都移除这条关系。列表不会提供自己。
5. 在日志中解除一个词条关联，预期只移除该日志与词条的链接，原日志和词条都保留。
6. 可新建一个“测试词条”并关联日志/其他词条，确认删除它。预期只清除该词条及其关系，日志原文、图片和其他词条不变。

## 4. 备份恢复与原有功能

1. 到“数据管理”导出完整备份。预期下载 JSON，提示包含词条；选择该文件后，摘要列出词条数、日志关联数和词条间关联数，先点“取消”检查无修改。
2. 打开 Edge InPrivate 窗口（Ctrl+Shift+N），访问同一地址，在“数据管理”选择该备份。核对摘要后点“确认恢复并刷新”。
3. 在独立窗口确认：词条正文、别名、分类、两天的关联说明、相关词条与原日志图片都可读取；词条日期链接返回正确日志。正常窗口数据不受影响。
4. 若有以前的 v1/v2 备份，可在独立窗口选择文件检查摘要。预期提示旧备份不含知识词条；确认恢复后词条为空，这是整体替换的结果。不要在正常窗口为测试覆盖当前数据。
5. 在正常窗口进入今日编辑或词条编辑，填入草稿后切换入口再回来；预期草稿保留。保存后刷新才应保留，未保存草稿不保证刷新后保留。
6. 启动番茄钟后切换入口，预期计时继续；今日/历史图文、展开收起及学习曲线仍可用。

## 5. 关联排版与检索

1. 打开已有词条并点击“编辑词条”，展开关联学习日志、其他词条、代码版本。勾选框应在左侧、文字紧随其后，长路径在列表内换行。缩窄浏览器后再检查一次。
2. 在“关联学习日志”中输入一篇笔记的日期或关键词，勾选匹配项。换成无关关键词后再清空，确认勾选仍在。确认后保存词条，或取消以保留原资料。
3. 从任意入口点顶部“检索”，输入一条已有的关键词，例如 `Tilemap` 或 `InputManager.cs`。结果按资料类型分组，可点击类型缩小范围。点击结果标题，核对原日志日期、词条或代码版本。
4. 若目标页有打开的编辑表单，检索结果会在新标签页打开。返回原标签页并回到编辑入口，确认草稿内容仍在。

## 6. 检索增强

1. 点顶部“检索”，输入一个只在长日志后半段出现的词。导入过 Day1 笔记时可用“后续随使用补充”。确认结果片段标亮该词，点击标题后日志自动展开并滚到高亮处。
2. 搜索一个词条别名或日志标签，点开后检查对应字段的高亮。通过顶部普通入口回到阅读页，浏览器后退可重新打开带定位的结果。可见的正文、标签和资料字段可定位，Markdown 隐藏的链接地址可在结果片段中核对。
3. 在“检索”中选择“代码版本”，勾选“搜索脚本正文（本地快照）”。若已导入 Whack-a-Mole 的 `InputManager.cs` 快照，可搜 `ScreenToWorldPoint`。确认结果显示版本、行号与关键词，点击后脚本预览滚到命中行，C# 语法颜色仍在。只有 GitHub 固定链接的版本可用路径或版本说明查找。

## 7. 关系视图

1. 打开一篇已有词条或代码关联的日志，点击正文上方的“查看关系”。当前日志应为中心卡片，直接关联的词条或代码显示在旁边。未补充过标签的连线会显示“相关”。
2. 点击一条连线，填入短标签（如“实现示例”）和可选说明，再点“保存关系”。确认图上的标签更新，点击资料卡可以回到原资料。
3. 从连线另一端的资料再次点“查看关系”。确认能读到相同标签和说明，刷新后仍可查看。缩窄窗口时，节点应沿纵向展开，点选连线后能看到下方详情。
4. 如需验收备份，在正常窗口导出完整备份，在独立窗口恢复后打开同一条连线，核对标签和说明。

## 8. 知识网络总览

可直接在内置演示工作区执行这一节的验收。

1. 从主导航进入“知识网络”，点击“打开知识网络演示”。新标签页顶部显示“知识网络演示工作区”，首次加载本版示例应有 96 个词条、24 篇日志、16 个代码版本和 340 条关联。
2. 用画布左上角的“搜索节点”分别查 `PPU`、`2D 渲染练习 1`、`DemoExample1_1.cs`，点结果定位相应节点。双击可打开原资料。
3. 定位“像素单位”，点“图层与筛选”，保持日志和代码图层开启，把“显示范围”切到一跳、两跳。检查聚焦时词条为紫色、日志为蓝色、代码为绿色。分别关闭两种资料图层，再通过“模块可见性”仅显示“2D 渲染”。展开右侧分类目录，检查名单与画布一致。
4. 在画布空白处按住左键拖动，确认适应窗口时也能平移。把鼠标移到一个节点上，按住 Ctrl 滚动滚轮，确认画布围绕指针缩放。把节点拖出原布局，确认关联线跟随。“适应窗口”应展示移动后的节点，“重置节点位置”应恢复自动排列。这些操作也可在全屏中使用。
5. 空白处右键选“新建词条”，也可用工具栏加号。新词条应默认使用当前分类，保存后定位到新节点。
6. 在演示中定位“待补充的实验”，点“添加连线”，在图上点终点，或用“搜索终点”查找“接口”。两端选好时可看到虚线。填写标签和说明后点“建立关联”，刷新后从词条页的“查看关系”核对，再回到图中移除连线。
7. 右下角开发者工具的“恢复内置演示数据”可重置演示。点顶部“返回个人知识网络”，确认原有日志、词条和代码仍在。

## 9. 模块可见性与返回

1. 刷新演示的“知识网络”。旧演示的原词条和资料仍在时，刷新会补齐缺少的共同资料样例关联。
2. 打开“图层与筛选”，在“模块可见性”点“全部隐藏”，再勾选“2D 渲染”和“物理与碰撞”。开启日志和代码图层，侧栏应有 3 条直接连线、1 篇共同日志和 1 个共同代码版本。勾选“只看跨模块关联”，两组词条仍可查看，画布上的连线应缩至 9 条。
3. 再勾选“输入与交互”和“场景与资源”，侧栏应有 33 条直接跨模块连线，可按模块对展开。关闭筛选面板，在画布右键“2D 渲染”的模块标题并点“隐藏此模块”。该组和相连的线应一起隐藏。“仅显示此模块”与“显示全部”也可快速更改范围。
4. 恢复步骤 2 的两个模块。点击“像素单位 ↔ 碰撞检测”，核对选中的连线与说明。返回侧栏“跨模块关联”，选共同日志“2D 渲染练习 1”，调整缩放和平移，再点“打开原资料”。浏览器后退或从顶部“知识网络”返回时，应继续原来的视角、选中项和模块筛选。
5. 关闭“只看跨模块关联”，选一个词条并设为一跳或两跳，拖动一个节点后打开原词条。普通返回应保留聚焦和手动布局。从词条点“在知识网络中查看”应重新定位该词条。

## 10. 整组移动、多选与图内编辑

可在 [知识网络演示](http://localhost:5185/?workspace=knowledge-demo#network) 使用以下步骤。

1. 打开“图层与筛选”，仅显示“2D 渲染”和“物理与碰撞”。拖动“2D 渲染”标题。该组背景和所有词条应同向移动，跨组连线跟随，“物理与碰撞”的节点位置保持原样。用 Ctrl+Z 撤销，用 Ctrl+Shift+Z 重做。点“重置节点位置”，再撤销一次，检查整组回到复位前的位置。
2. 按住 Shift 单击两个词条，从空白处按住 Shift 拖出选框再加入其他节点。右侧显示所选项，拖动其中任意一个节点应带动全部可见选中节点。再次 Shift 单击可取消选中。点“批量改分类”，填一个新分类并保存，核对所选词条进入新组，再撤销。
3. 右键模块标题，选“整理成员”。点“清空选择”，搜索或勾选一两个成员，填目标分类并保存。检查被勾选的词条和原有关系。撤销后右键标题选“重命名分类”，可先试新名称，再试改成现有分类。合并前表单会显示受影响的词条数。用撤销和重做检查分类。
4. 右键词条选“编辑词条”，改名称或正文，再勾选或取消一项关联。保存后应仍在知识网络，图上使用更新后的词条和连线。画布中按 Ctrl+Z，检查内容与关联恢复。打开词条原资料再返回，检查视角和布局。
5. 刷新演示。已保存的编辑或撤销结果应保留，画布恢复自动布局，撤销与重做按钮为不可用。可用演示工作区的“恢复内置演示数据”清理测试编辑。

## 11. 资料分组与所选节点关系

1. 打开[知识网络演示](http://localhost:5185/?workspace=knowledge-demo#network)。拖动“学习日志”和“代码版本”的分组标题，检查组内节点与关联线跟随。按 Ctrl+Z 撤销一次，再按 Ctrl+Shift+Z 重做。
2. 右键“学习日志”标题选“隐藏此模块”，确认日志和相连的线从画布隐藏。打开“图层与筛选”，点“学习日志”恢复。对“代码版本”重复，确认恢复后沿用拖动产生的偏移。
3. 在“模块可见性”仅勾选“2D 渲染”，关闭“只看跨模块关联”。按住 Shift 选择“像素单位”和“精灵图集”，在侧栏点“仅查看所选”。默认只显示两个选中节点，内置样例中两者没有直连。勾选“显示中间节点（两跳）”，可看到经过“精灵切片”等节点的路径。中间节点使用虚线边框。
4. 点击一条线查看关系说明。按住左键拖动画布空白处，确认可平移且仍显示关系详情。单击空白处，确认侧栏回到所选节点。再单击“精灵切片”或“像素单位”打开节点详情，单击空白处也应回到原来的所选节点。节点选择、中间节点开关和平移缩放都应保留。点“返回完整视图”，检查原来的筛选和视角是否恢复。
5. 在 Edge 点击“全屏画布”，右键词条选择“编辑词条”。用实体键盘短按一次 Esc，松开后确认弹窗关闭且画布仍处于全屏。再按 Esc 或点击“退出全屏”可退出全屏。

## 反馈重点

请优先反馈：从日志创建词条是否顺手；词条中原日志列表及说明能否帮助找回情境；分类和别名是否够用。概念之间若需要更具体关系，给出真实的一对概念及使用场景，再评估扩展。
