# 图文学习记录 v1：验收步骤

本指南对应 2026-11-05 的 Day1 教程材料。自动测试已在独立浏览器内通过，用户也已确认验收未发现问题。以下步骤保留用于后续回归；自动测试不替用户向正式数据区录入笔记。

## 1. 导入 Day1

1. 打开 `http://localhost:5185/`；如打不开，在项目目录执行 `npm run dev -- --port 5185`。
2. 点击顶部“今日学习”，在“今日学习记录”展开“导入图文学习记录（Markdown + 图片）”。
3. 学习日期选 `2026-11-05`，Markdown 选 Day1 的 `学习整理.md`。
4. 在“配套图片”文件选择器进入该文件同级的 `images` 文件夹，选中其中全部 15 张图片（可用 Ctrl+A）。
5. 点“检查并预览”。预期：显示 15 处引用、15 张匹配图片；预览中截图与操作说明对应。
6. 点“保存到该日期”；如果已有笔记，按钮为“确认追加到该日期”。预期：明确提示已保存，原时长不变。重复确认导入会追加内容，请勿为测试反复导入同一稿。

## 2. 刷新回看与补充

1. 刷新页面，切换顶部“历史回顾”，在“学习历史”的“定位学习日期”选择 `2026-11-05`。
2. 长文先点“展开全文”。预期：可读到标题、步骤、来源链接和截图；点击截图可在新标签页看原图。
3. 点“编辑 / 补充记录”，在末尾增加一句测试补充（如“待验证：换 32×32 素材后再比较 PPU”），点“保存补充”。
4. 刷新并再次定位该日期。预期：补充保留，原图、原文和学习时长均保留。
5. 若要检验取消，编辑后点“取消编辑”。预期：未保存文字不进入日志。

导入不增加番茄钟数、不自动完成技能、不打卡。已有的本地 `原始记录.md` 链接会显示“本地资料”，请回原材料目录查看；本功能只导入所选整理稿和引用图片。

## 3. 图文备份与恢复（推荐用独立浏览器验证恢复）

1. 导入成功后切换顶部“数据管理”，点“导出完整备份”。预期：下载 JSON，提示包含 15 张图片（若已有其他图片，数量可能更多）。
2. 选择刚导出的备份，核对日志数、任务数和图片数，先点“取消”。预期：正式数据不变。
3. 打开 Edge 新的 InPrivate 窗口（Ctrl+Shift+N），访问同一地址；这个窗口的存储与正常窗口隔离。
4. 在 InPrivate 中切换“数据管理”并选择该备份，核对摘要后点“确认恢复并刷新”。
5. 切换“历史回顾”并定位 `2026-11-05`，点“展开全文”。预期：完整正文、补充内容和 15 张图片仍可读。

这一步无需清空正常窗口数据。关闭所有 InPrivate 窗口后，其中的测试数据会被浏览器清除；正常窗口数据保持独立。

## 4. 页面导航与布局

1. 依次点击顶部五个入口，确认每次只展示对应模块；刷新和浏览器前后退应维持入口。
2. 在“今日学习”启动番茄钟，切换到其他入口等待几秒，再返回；剩余时间应继续减少，不重置。
3. 在“历史回顾”编辑一条笔记但不保存，切到“成长记录”再返回。草稿应保留，可以保存或取消。
4. 展开长图文并滚动到底部，顶部导航应保持可见，可直接切到数据管理。
5. 在“今日学习”进入编辑，桌面双栏下两侧标题和内容框的顶部、底部应对齐；分别滚动其中一侧不改变两框高度。
6. 在“历史回顾”定位长笔记，默认只显示一段预览。点击“展开全文”后能读到结尾；顶部“收起正文”或文末“收起并返回正文开头”恢复预览。短笔记直接显示全文。

## 反馈建议

请说明哪一步与预期不同，尤其是图片匹配/阅读、追加方式、历史补充和来源回看是否顺手。跨记录关联与词条目录现见 [知识词条验收指南](./KNOWLEDGE_ACCEPTANCE.md)；日志正文检索、直接粘贴截图尚未实现，仍按后续真实困难选择改进。
